# B-727 の水面を Vulkan で比較する

リポジトリのルートで次を実行する。出力先は新規ディレクトリを指定する。

```powershell
python ai_loop/windows/water_gpu.py ../water-output --godot bin/godot.windows.editor.x86_64.console.exe
```

Python 3.9 以降、B-727 を含む editor バイナリ、Forward+ Vulkan で描画できる画面が必要。Linux でも対応する editor と画面を指定して実行できる。ソフトウェア Vulkan の時間は計測手順の確認に使える。

水の見本を一時ディレクトリにコピーし、同じカメラとライティングで3ケースを撮る。

- `dry.png` は水面なし。
- `water.png` は既定の水面。
- `water_no_reflection.png` は同じ水面で画面空間反射だけ停止。空とプローブからの反射は残る。

`report.json` に各ケースの Vulkan デバイス、解像度、GPU 時間の中央値と95パーセンタイル、中央値の差が入る。既定は1280×720、各ケースのウォームアップ60フレーム後に180フレーム採取。上限60fps、VSync 無効。短い試走は `--frames 12 --resolution 640x360`。フレーム時間はシーン全体の描画を含むので、差は環境や実行順で揺れる。同じ実機と解像度で複数回測り、中央値の差を照合する。

水の動きには実行時刻が影響する。画像は、浅瀬と深い所の色、岸の泡、底の帯の屈折、奥の塔や杭の反射を目視で比較する。最初の描画エラー、Vulkan のフォールバック、無効な計測値、タイムアウトで終了コード1になり、その時点までの結果とログを残す。
