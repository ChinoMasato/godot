# COORDINATION — 三者連携ボード

このファイルが、オーナー・Muse（リード）・Claude Code・Codex の
**唯一の連携窓口**です。人間がメッセージを中継しなくて済むよう、
状態・担当・質問はすべてここに集約します。git 経由の非同期連携です。

## 役割

| 役割 | 担当 | 責務 |
|---|---|---|
| オーナー | 千野正登 | 設計判断と最終承認。ここは読むだけでよい |
| リード | Muse | 統合窓口。各ブランチの取り込み、ai-native へのマージ、LEDGER への決定反映、質問の集約とオーナーへの提示 |
| 実装 | Claude Code（ローカルセッション） | 担当項目の実装と検証、記録 |
| 実装 | Codex（ローカル） | 担当項目の実装と検証、記録 |

## 運用ルール

1. **セッション開始時**: `git fetch` で最新の `ai-native` を取り込み、
   このファイルと `CLAIMS.md`、`BACKLOG.md` を読む。
2. **セッション終了時**: 下の状況ボードで**自分の行だけ**を更新し、
   自分のブランチへ push する（push できない環境では、更新内容を
   記録ファイルとしてリードへ渡す）。
3. **質問・相談**は下の「質問・相談」節に、宛先と日付つきで書く。
   回答も同節に追記する。チャットや口頭で済ませない（記録が正）。
4. **正式な決定**はオーナーの承認を経て、リードが `LEDGER.md` に
   反映した時点で確定する。このボードの記載は提案・状況の共有であり、
   決定そのものではない。
5. 担当や触るパスが衝突したら、作業を止めて質問節に書く。
   先に宣言した側（`CLAIMS.md`）が優先。
