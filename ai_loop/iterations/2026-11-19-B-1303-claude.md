# B-1303 UI テーマ／プリセットと日本語フォントのサブセット — claude (2026-11-19)

- ブランチ: ai-native に直接反映。着手前に CLAIMS を push した。
- BACKLOG B-1303: ジャンル別の見た目（和風・SF・ファンタジー等）を1コールで適用する。日本語フォントのサブセット同梱の作法（B-1003 の文字化けの教訓）も含める。
  - 判定: 同じ UI 仕様に2テーマを適用した比較画像が iterations に残ること（3テーマで残した）。

## 内容

- **テーマのプリセット**（`ai_loop/presets/ui/*.json`、新規）: UZUUI.create_theme（B-1302）の値の組み合わせ。

  | テーマ | 見た目 |
  |---|---|
  | `wafu`（和風） | 藍のパネル、朱のボタン、金の縁、角は小さめ |
  | `sf` | 暗いガラスのパネル、シアンの光る縁、角はほぼ直角 |
  | `fantasy` | 茶色い革のパネル、金の太い縁、角は丸い |

  - `uzu.py ui --theme NAME` で、仕様のテーマの上に重ねる（プリセットの値が勝つ）。同じ仕様を、テーマを変えるだけで着せ替えられる。
- **日本語フォントのサブセット**（`ai_loop/ui_font.py`、新規）: 2つの WOFF2 を作り、それぞれの隣にライセンスを置く。
  - `<名前>_latin.woff2`: Open Sans から、ASCII と Latin-1。
  - `<名前>_ja.woff2`: Droid Sans Japanese から、UI の仕様が使う全文字と、フォントにある仮名・日本語の約物（あとで文を少し変えても出るように）。
  - 元のフォントは、どちらもリポジトリの thirdparty/fonts（Apache 2.0）。読むだけで、thirdparty は変えていない。
  - 仕様の文字のうち、どちらのフォントにもない字は「missing」として誤りにする（試した例: 𠮷、☃）。
  - `uzu.py ui --font-subset`:
    1. サブセットを `res://fonts/` に書く。
    2. テーマを「`font`＝Latin、`font_fallback`＝日本語」にする。
    3. ui_tool.gd は、FontVariation（Latin を本体、日本語を fallback）にまとめる。
    4. インポートしてから組み立てる。
  - fontTools と brotli が要る（`pip install fonttools brotli`）。なければ、その旨の誤りを返す。
- ui_tool.gd: テーマに `font_fallback` を足した。MCP ui_build に `theme`／`font-subset` を足した。

## 確認

- 同じ HUD の仕様（`look_samples/specs/hud.json`）に3テーマと既定を当て、村の上に撮った: `ai_loop/look_samples/compare/b1303_themes.png`。
  - パネル・ボタン・バー・縁の色と、角の丸さが、テーマごとにはっきり違う。
  - 配置と文字は同じまま。
- **文字化けの再現と解消**: fontconfig に空の設定を渡し、OS のフォントが見えない状態（Web と同じ）で撮った（`compare/b1303_font_subset.png`）。
  - サブセットなし: 日本語がすべて豆腐（□）になる。B-1003 と同じ。
  - `--font-subset` あり: 正しく出る。
  - サブセットの大きさは、合わせて **29 KB**（元のフォントは 502 KB）。この HUD で使う字は 53 字。
- `uzu.py selftest engine` に5項目を足した:
  - テーマ sf の色が保存される。知らないテーマは、一覧付きの誤りになる。
  - 仕様からの文字の取り出し。
  - fontTools があるときは、サブセットを作る（100 KB 未満、ファイルあり）。ないときは skip と出す。
  - fontTools 入りの venv では、all で ok（サブセットも実行）。システムの python3 では、engine で ok（サブセットは skip）。
- `mcp_server.py --self-test`: ok。エンジンのコードは変えていない。

## 残り

- Web 書き出し（B-1003／B-1306）で、実際にサブセットが効くことを、ブラウザで確かめる。
- テーマに合うフォント（明朝体など）は、ライセンスの明確な物を見つけて `--font-ja` で渡せる。同梱するかどうかは、オーナーの判断。
