# B-1219 モデル品質の底上げ — 第1段: 建物（UZUWorldGen の街） — claude (2026-11-19)

- ブランチ: ai-native に直接反映。着手前に CLAIMS を push した。
- 順序: リードの着手順メモ（B-1219 本実装が次）と、オーナー指示「建物を最優先」に従った。
- 方針:
  - この環境には Blender がない。そのため、エンジン内（C++）の手続き生成で建物を部品から作る。
  - テクスチャセットは形と同時に生成する。
  - 密度は、繰り返し部品（窓枠の MultiMesh）で稼ぐ。
  - 辺は面取りで守る（オーナーとの確認「建物の低ポリ化は辺を守る方式、密度は部品の繰り返しで」）。
- Blender のハイポリ→法線ベイク工程（B-1205 の残り）と岩・自然物は、この段の範囲外。

## 内容

### modules/uzu_worldgen/uzu_world_gen.cpp（generate_city）

- **新しいオプション**:
  - `detail`: `"high"`（既定）／`"simple"`（これまでの箱）
  - `textures`: 既定 true
- **建物の部品レシピ**（`detail=high`）。辺は面取りする。

  | 部位 | 部品 |
  |---|---|
  | 壁 | 漆喰か、約35%がレンガ |
  | 足元 | 石の基壇（村 0.45 m、町 0.75 m） |
  | 階の間 | 帯（町は約75%） |
  | 角 | 隅柱（約50%） |
  | 正面（ブロックの中心から外を向く辺） | 枠と2枚の鏡板の扉、石の段。町では庇、村では約40%に庇 |
  | 窓 | 窓枠（縦枠・頭のコーニス・窓台・縦桟・横桟。村では雨戸） |
  | 切妻屋根 | 軒の出 0.45 m、けらばの出 0.3 m、厚み 0.12 m（鼻隠し・破風・軒裏）、棟瓦、約45%に煙突 |
  | 陸屋根 | コーニス、パラペット（笠木つき）、屋上機器。4階以上の約60%に塔屋、都市では約40%に給水塔 |

- **面取りした箱 `add_cbox`**: 6面＋辺12本の帯＋角8つの三角形。
- **外周の帯 `add_ring`**: 基壇・階の帯・コーニスに使う。上の外角を面取りする。
  - そのため、`inset_quad` に外側へのオフセット（形の確認なし）を足した。
- **窓枠**:
  - 1つのメッシュを、ブロックごとの MultiMesh（`WindowFrames_i_j`）で繰り返す。
  - 160 m より先で消える（visibility range とフェード）。ブロック単位なので、遠いブロックから消える。
- **乱数**:
  - 部品と点灯窓には、別の乱数 `drng` を使う。
  - そのため、`simple` と `high` で敷地・建物・窓の数が同じになる（単体テストで確認）。
  - 副作用: `simple` でも、点灯窓の選び方がこれまでと変わる。街割りも少し変わる。点灯窓の乱数が、もう街割りの乱数を消費しないため。
- **手続き PBR テクスチャセット**（形と同時に生成）:
  - 継ぎ目なくタイルする値ノイズで、明度（頂点色に掛ける）・高さ（→法線マップ）・粗さの3枚を作る。

  | 種類 | 1タイルの大きさ | 中身 |
  |---|---|---|
  | 漆喰 | 2 m | — |
  | レンガ | 0.75 m | 3個×10段、目地 |
  | 瓦 | 1.2 m | 6枚×4段の丸瓦、下端が厚い |
  | 石 | 1.2 m | 0.6×0.3 m の切石 |
  | コンクリート | 2 m | — |

  - MeshBuilder に、面ごとの平面 UV と接線を足した（u は面の水平方向、v は面の下向き）。
  - 漆喰の凹凸は、一度強すぎて汚れて見えた。弱めた（bump 3→1.2）。
- **結果**:
  - `counts.parts`: plinths, string_courses, pilasters, doors, chimneys, roof_props, window_frames
  - `buildings_detail`: detail, textures, about
  - 三角形数には、部品と窓枠（インスタンス数×メッシュ）を含める。

### 保存（ai_loop/map_tool.gd）

- 複数のノードが使うテクスチャとメッシュ（窓枠）を、先に1回だけ外部ファイル（`tex_N.res`、`mesh_WindowFrames.res`）に出すようにした。
- それまでは、窓枠のブロックごとにテクスチャを重複して持っていた。町の保存は 11 MB から 2.7 MB になった。

### モデル品質指標（ai_loop/engine_tool.gd の rich、uzu.py look rich）

- `model_quality` の中身:

  | 項目 | 意味 |
  |---|---|
  | `pbr_coverage` | 色と法線マップを持つ三角形の割合 |
  | `textured_share` | テクスチャを持つ三角形の割合 |
  | `bevel_share` | 2面が共有する辺を角度で分けたときの、面取り（30〜60°）÷（面取り＋鋭い辺 75° 超） |
  | `triangles_per_m2` | 表面積あたりの三角形数 |
  | `cheap_meshes` ／ `cheap` | 1.5 m 超で 24 三角形以下、面取りもテクスチャもない素の箱 |
  | `sharpest` | 鋭い辺の多いメッシュ上位6つ（メッシュごとの bevel_share・法線の向きの数・PBR の有無） |

  - 大きなメッシュは、先頭 2 万三角形を標本にする。
  - 面取り率は、最初は 15〜75° で数えていた。木の塊（球に近い多面体）の辺が面取りに入り、simple でも 0.88 になった。範囲を 30〜60° にし、法線の向きが 64 種を超える曲面のメッシュは集計から外した（`curved_meshes`）。
- 予算キー: `min_pbr_coverage`、`min_bevel_share`、`max_cheap_meshes`。
- ヒント:
  - 素の箱がある。
  - ほとんどの辺が鋭い。
- `look shot` が `--scene` を無視して main scene を撮っていたのを直した（比較撮影に必要だった）。

## 残り（B-1219 の続き）

- ハイポリ→法線／AO ベイク→実用密度の工程（Blender ブリッジ、B-1205 の残り）。ベイク欠落率の指標も含む。ローカル（Blender のある環境）向け。
