# B-728 水面の格子・反射・岸の修正 — Codex

B-727 の Windows GPU 確認で指摘された4点を対象にした。作業ブランチは `agent/b-728-codex`。公開 API とシェーダーパラメータは従来どおり。

- 波の値ノイズに五次補間を使い、波の組とオクターブで格子の向きをずらした。
- 画面空間反射は、レイが深度面をまたいだヒットを3回の二分探索で絞り、得られた UV で色を取得する。粗い探索の28歩とヒット許容幅は維持した。
- 岸の泡は向きと周波数の異なる二つのノイズを混ぜ、泡の濃さの切り替えを緩やかにした。
- 水の見本に手前岸を追加し、底の斜面と重ねた。画面下に露出していた水面メッシュの端を覆いつつ、水位と岸の接点には泡を残す。

## 検証

- shader の独立構文検査はエラー・警告各0。clang-format と `git diff --check` も成功。
- Linux editor のビルド、全単体テスト **1520 pass、0 fail、3 skip**。531992 assertions pass。ビルドは37.62秒。ログは `/workspace/artifacts/b-728/final-build-test.log`。
- 初回ビルド中のベース取り込みで、追加の UZUSfx が登録側だけ再コンパイルされてリンクに失敗した。取り込みを完了させて別のビルドを実行し、UZUSfx とそのテストを含めて成功した。その後のベース `f67eb55833` との差は担当表のみ。
- 同じカメラ・解像度・水面設定で Forward+ の旧・新版をソフトウェア Vulkan で撮影。新版は Mobile Vulkan と Compatibility OpenGL でも撮影し、3方式すべてで描画エラー0。Mobile／Compatibility ではシーンの未対応な画面効果について既存の警告が出る。
- 640×360 の Forward+ 比較で、下端の線があった帯（x=20〜619、y=310〜323）を測定した。Rec.709 の重み付き8bit明るさで、上下隣接画素の平均より15を超えて明るい画素は **1220 → 0**。水際の泡は残った。
- 撮影とログは `/workspace/artifacts/b-728/` の `before.png`、`after.png`、`mobile.png`、`gl_compatibility.png` と同名のログ。ソフトウェア実行の時間は Windows GPU の性能値として扱わない。

Windows GPU では、B-727 の再確認と同じ条件で水面の格子、塔の反射の段差、岸の泡を比較する。結果を確認してからリードが統合・台帳更新を行う。
