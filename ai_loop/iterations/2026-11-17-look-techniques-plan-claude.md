## 技法 → エンジン機能の対応（全要素）

| # | 技法（原理の要約） | エンジンで使う機能 | 項目 |
|---|---|---|---|
| 1 | 空気遠近（細かい粒子）: 遠いものほど青くなる。乾いた空気で強く出る。朝夕は光が長い距離を通るので赤くなる | `PhysicalSkyMaterial` のレイリー散乱、フォグの色と空気遠近（遠景が空の色に寄る） | B-702 |
| 2 | 空気遠近（大きな粒子）: 湿った空気では遠景が白くかすむ（日本の風景に多い）。雲が白いのも同じ理由 | `PhysicalSkyMaterial` のミー散乱、白っぽいフォグ、高さフォグ（低い所ほど濃い霞） | B-702 |
| 3 | 順光と逆光: 順光は色と立体感がよく見え、逆光はシルエットと遠近感が強く出る。影の面ほど空気遠近の変化が大きい | 太陽の向きのプリセット（順光／逆光／朝夕）、逆光時のフォグ強化 | B-702（太陽の向き）、B-705（演出） |
| 4 | 3点照明: キー光（主光源）、フィル光（影を少し起こす）、バック光（輪郭を立てる） | 照明のプリセット: 太陽＋影なしの補助光＋背面光 | B-705 |
| 5 | 木漏れ日: 高い所の葉の影ほど、太陽の形（丸）にぼける。低い所の葉の影はくっきり | 影の柔らかさが距離で変わるソフトシャドウ（`light_size`）。**B-701 の「高」で対応済み** | 済（B-701）。確認用シーンを B-709 で用意 |
| 6 | 彩度とメリハリ: 中間の明るさの色は彩度を控えめに。影とハイライトはさらに灰色寄りにすると自然 | 明るさごとに彩度を変える色調整 LUT（`adjustment_color_correction` に Texture3D） | B-703 |
| 7 | 面とメリハリ: 明るい面と暗い面の境（物の縁）のコントラストを上げると、形がはっきりする | 局所コントラスト（縁の強調）の後処理シェーダー | B-703b（新しい後処理の仕組みが要る。設計承認が必要） |
| 8 | 地面は明るく: 日の当たる面は想像以上に明るい（ほぼ白）。カメラで見たような明るさにする | 露出の調整、自動露出（`CameraAttributes`） | B-706 |
| 9 | いろいろな遠近感: 遠景に色を重ねる、コントラストを下げる、ぼかす、描き込みを減らす | 重ねる・下げる → フォグ（B-702）。ぼかす → 遠景ぼかし（被写界深度）。描き込みを減らす → 表示距離・LOD | B-706（ぼかし）、LOD は素材側 |
| 10 | 見せ場に描き込みを集める: 主役に視線を集め、脇役は大まかに | 被写界深度（ピント）、周辺減光 | B-706（ピント）、B-703b（周辺減光） |
| 11 | 表面下散乱: 肌・葉・半透明な物は、光が中で散って影の境目が明るく色づく。逆光で強く出る | `StandardMaterial3D` の表面下散乱、透過、バックライト | B-704 |
| 12 | 透明感: 大きなグラデーション、くっきりしたハイライト、色相の変化 | 素材のプリセット（ガラス・半透明）、空のグラデーション | B-704 |
| 13 | 水: 水の色・水底の透過・水面の反射の3つに分ける。遠くの水面ほど浅い角度になり反射が強い | 水の素材（角度で反射が変わる、深さで色が変わる、透過）、画面空間反射（SSR） | B-704 |
| 14 | 照明の明るさ（夜）: 光が届く所だけを明るくする。照明そのものも真っ白にせず色をのせる | 色のついた発光＋Glow、光の届く距離での減衰、夜の環境プリセット | B-705 |
| 15 | 雲: 光の当たる側が明るく下ほど暗い。半透明なので大きなグラデーション。地平線の近くほど密に重なる | 空のシェーダーに雲（明暗のグラデーション、地平線で密になる分布） | B-707 |
| 16 | 抜け感: 主役の周りに奥の空間が見えるように配置する | 構図の話。エンジンの機能ではなく、授業の教材・サンプルシーンで扱う | 対象外（教材） |
| 17 | 建物・ビル・レンガ（資料）: 風土で形が決まる建物、ビルのシルエット、レンガの積み方 | 素材集・サンプル素材の話。エンジンの機能ではない（レンガの手続き的なシェーダーは将来の候補） | 対象外（素材集） |
| 18 | 重ねる: 物どうしのシルエットを重ねると密度と前後関係が出る。地平線（目の高さ）の近くほど物の密度が高いのが自然 | 構図の話。サンプルシーンと、配置の密度を測る検査（B-711 の画像解析で、地平線付近の密度を見る） | B-709、B-711 |
| 19 | 構図いろいろ: 中心（日の丸）、三分割、三角、逆三角、ジグザグ、パターン。黄金比は必須ではない | エディタのカメラ表示に構図ガイド（中心・三分割・対角線・三角）を重ねる | B-710（エディタ UI。設計承認が要る） |
| 20 | 色が濁るとき: 光の三原色をすべて混ぜると濁る。全体の彩度が均一すぎたり明暗差が弱すぎたりしても濁って見える | 画像の色解析: 彩度と明度の分布、濁り（3色すべてが一定以上の色）の割合を測る | B-711（AI 用の検査ツール） |
| 21 | 色のバランス: ベース 70%・メイン 25%・アクセント 5% くらいの面積比。慣れないうちは色を3色以下に絞る | 画像の色解析: 色相ごとの面積比を出し、ベース／メイン／アクセントの比率を報告する | B-711 |
| 22 | 色の決め方: 色は2色以上の組み合わせで決まる。日なたの面は黄色寄り、影の面は空の反射で青寄り。地面の照り返しも効く | 暖色の太陽＋空からの環境光（青）＋照り返し（SSIL）。**B-701／B-702 で対応済み**。B-705 の補助光も空の青にする | 済、B-705 |
| 23 | 画角: 広角は遠近感が強く、望遠はスケール感が強い。迷ったら標準よりやや望遠寄り（アニメの構成もこちらが多い） | カメラのレンズ・プリセット（広角・標準・望遠の FOV）。Godot の Camera3D の初期値 75° はやや広角 | B-712 |
| 24 | 風景画のパース: 遠くの物は想像以上に小さい。目の高さの近くほど密度を上げる。手前は暗く大きく | 構図と配置の話（サンプルシーン、教材） | B-709、教材 |
| 25 | 人物とパース: 目の高さ（例 160cm）を基準に人物を置くと、どの距離でも頭の高さがそろう | カメラの高さのプリセット（立った目線 1.6m、座った目線 0.8m など） | B-712 |
| 26 | アオリ・俯瞰と消失点: 縦の線を平行に保つ（2点透視風）と、見上げ・見下ろしでも落ち着いた構図になる | カメラを水平に保ったまま写る範囲を上下にずらす「シフト」（Camera3D の frustum_offset、PROJECTION_FRUSTUM） | B-712 |
| 27 | 1・2・3点透視: 同じ理論で、1枚の絵の中で混在してよい。何点透視かより、構図と画角から考える | 3D では自動的に正しくなる。教材の話 | 対象外（教材） |
| 28 | 魚眼・パノラマ（正距円筒）: 魚眼は画面の端まで自然に見え、パノラマは横に長い画面を作れる | 魚眼・パノラマの投影。Godot のカメラには無いので、後処理での歪み、またはキューブマップからの変換が要る | B-713（新しい機能。設計承認が要る） |

## 項目と順番（おすすめ順）

1. **B-702 空気遠近の2モードと時間帯**（#1, #2, #3 の太陽の向き）: 設定だけで済み、見た目の変化が一番大きい。日本の湿った空気感は U.ZU らしさにもなる。
2. **B-703 色調整 LUT**（#6）: LUT を数値で作り、`adjustment_color_correction` に入れる。既存の仕組みだけで済む。
3. **B-704 素材のプリセット**（#11, #12, #13）: 肌・葉（表面下散乱、透過）、ガラス、水。
4. **B-705 照明のプリセット**（#3 の演出, #4, #14）: 3点照明、逆光、夜の照明。
5. **B-706 露出と遠景ぼかし・ピント**（#8, #9, #10）: 自動露出、被写界深度。
6. **B-707 雲**（#15）: 空のシェーダーで雲を描く。新しいシェーダー素材になるので、置き場所は設計の判断（`ProceduralSkyMaterial` の拡張か、同梱のシェーダーか）。
7. **B-711 画像の色解析（AI 用の検査ツール）**（#18, #20, #21）: スクリーンショットから、色の面積比（ベース／メイン／アクセント）、濁り、彩度・明度の分布、地平線付近の密度を JSON で出す。エンジンは変えない。A-1 と組み合わせ、AI が自分で「色が濁っていないか」を確かめられる。
8. **B-712 カメラのレンズ・プリセット**（#23, #25, #26）: 広角・標準・望遠の FOV、目の高さ、水平を保ったまま上下にずらす「シフト」。エンジン内部の関数＋エディタ（UI は確認する）。
9. **B-703b 局所コントラストと周辺減光**（#7, #10 の一部）: 新しい後処理の仕組み（CompositorEffect の内蔵版）になるので、公開 API の設計承認が要る。承認待ちの間は後回しにする。
10. **B-709 確認用のサンプルシーン**: 木漏れ日・水・逆光・重なり・目の高さの密度など、各項目を見比べるためのテストシーン一式（A-1 で撮る）。
11. **B-710 構図ガイド**（#19）: エディタのカメラ表示に、中心・三分割・対角線・三角のガイドを重ねる。エディタ UI なので設計承認が要る。
12. **B-713 魚眼・パノラマの投影**（#28）: 新しい描画機能なので、設計承認を取ってから。

## 判定（全項目共通）

- 機械判定: プリセットの値の単体テスト、全テスト pass、クラスの初期値が変わっていないこと（既存シーンの互換）。
- 見た目: A-1（ヘッドレス描画）で同じテストシーンを撮り、前と後を並べてオーナーが判断する。
- 公開 API を増やす項目（B-703b、B-707 の置き場所によっては）は、実装前に設計の承認を取る。
