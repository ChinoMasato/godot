## 技法 → エンジン機能の対応（全要素）

| # | 技法（原理の要約） | エンジンで使う機能 | 項目 |
|---|---|---|---|
| 1 | 空気遠近（細かい粒子）: 遠いものほど青くなる。乾いた空気で強く出る。朝夕は光が長い距離を通るので赤くなる | `PhysicalSkyMaterial` のレイリー散乱、フォグの色と空気遠近（遠景が空の色に寄る） | B-702 |
| 2 | 空気遠近（大きな粒子）: 湿った空気では遠景が白くかすむ（日本の風景に多い）。雲が白いのも同じ理由 | `PhysicalSkyMaterial` のミー散乱、白っぽいフォグ、高さフォグ（低い所ほど濃い霞） | B-702 |
| 3 | 順光と逆光: 順光は色と立体感がよく見え、逆光はシルエットと遠近感が強く出る。影の面ほど空気遠近の変化が大きい | 太陽の向きのプリセット（順光／逆光／朝夕）、逆光時のフォグ強化 | B-702（太陽の向き）、B-705（演出） |
| 4 | 3点照明: キー光（主光源）、フィル光（影を少し起こす）、バック光（輪郭を立てる） | 照明のプリセット: 太陽＋影なしの補助光＋背面光 | B-705 |
| 5 | 木漏れ日: 高い所の葉の影ほど、太陽の形（丸）にぼける。低い所の葉の影はくっきり | 影の柔らかさが距離で変わるソフトシャドウ（`light_size`）。**B-701 の「高」で対応済み** | 済（B-701）。確認用シーンを B-709 で用意 |

| 7 | 面とメリハリ: 明るい面と暗い面の境（物の縁）のコントラストを上げると、形がはっきりする | 局所コントラスト（縁の強調）の後処理シェーダー | B-703b（新しい後処理の仕組みが要る。設計承認が必要） |

| 10 | 見せ場に描き込みを集める: 主役に視線を集め、脇役は大まかに | 被写界深度（ピント）、周辺減光 | B-706（ピント）、B-703b（周辺減光） |
| 11 | 表面下散乱: 肌・葉・半透明な物は、光が中で散って影の境目が明るく色づく。逆光で強く出る | `StandardMaterial3D` の表面下散乱、透過、バックライト | B-704 |
| 12 | 透明感: 大きなグラデーション、くっきりしたハイライト、色相の変化 | 素材のプリセット（ガラス・半透明）、空のグラデーション | B-704 |
| 13 | 水: 水の色・水底の透過・水面の反射の3つに分ける。遠くの水面ほど浅い角度になり反射が強い | 水の素材（角度で反射が変わる、深さで色が変わる、透過）、画面空間反射（SSR） | B-704 |

## 項目と順番（おすすめ順）

1. **B-702 空気遠近の2モードと時間帯**（#1, #2, #3 の太陽の向き）: 設定だけで済み、見た目の変化が一番大きい。日本の湿った空気感は U.ZU らしさにもなる。
2. **B-703 色調整 LUT**（#6）: LUT を数値で作り、`adjustment_color_correction` に入れる。既存の仕組みだけで済む。
3. **B-704 素材のプリセット**（#11, #12, #13）: 肌・葉（表面下散乱、透過）、ガラス、水。
4. **B-705 照明のプリセット**（#3 の演出, #4, #14）: 3点照明、逆光、夜の照明。
5. **B-706 露出と遠景ぼかし・ピント**（#8, #9, #10）: 自動露出、被写界深度。
6. **B-707 雲**（#15）: 空のシェーダーで雲を描く。新しいシェーダー素材になるので、置き場所は設計の判断（`ProceduralSkyMaterial` の拡張か、同梱のシェーダーか）。
7. **B-703b 局所コントラストと周辺減光**（#7, #10 の一部）: 新しい後処理の仕組み（CompositorEffect の内蔵版）になるので、公開 API の設計承認が要る。承認待ちの間は後回しにする。
8. **B-709 確認用のサンプルシーン**: 木漏れ日・水・逆光など、各項目を見比べるためのテストシーン一式（A-1 で撮る）。

## 判定（全項目共通）

- 機械判定: プリセットの値の単体テスト、全テスト pass、クラスの初期値が変わっていないこと（既存シーンの互換）。
- 見た目: A-1（ヘッドレス描画）で同じテストシーンを撮り、前と後を並べてオーナーが判断する。
- 公開 API を増やす項目（B-703b、B-707 の置き場所によっては）は、実装前に設計の承認を取る。
