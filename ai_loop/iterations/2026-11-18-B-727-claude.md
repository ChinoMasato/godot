## 分かったこと（前の説明の訂正）

- Godot の SSR（画面空間反射）は、半透明の素材には効かない。
- B-704 の `MATERIAL_WATER` は半透明なので、画質「高」でも景色は映っていなかった。映っていたのは空と反射プローブだけ。
- オーナーへの前の説明（「画質『高』では SSR で周りの景色が映る」）は誤りだった。新しい水は、自前の画面空間反射を持つ。

## 内容

- **エンジン**（`scene/3d/look_preset_3d.{h,cpp}`、`scene/3d/uzu_look.{h,cpp}`）:
  - `LookPreset3D::create_water_material()` と `create_water(size)` を追加した。
  - `UZULook.create_water_material()` と `UZULook.add_water(root, position, size = (10, 10), options = {})` を追加した。
    - options はシェーダーの値を設定する。知らないキーは誤りになり、何も追加しない。
    - 水面は細かく分けた PlaneMesh（1 m に約2頂点、上限 200）で、影は落とさない。
  - シェーダー（spatial、1本）の中身:
    - **深さ**: 深度バッファから、視線の上で「水面から底まで」の水の量を測る。
      - 水の色は `shallow_color` → `deep_color` に変わる。
      - 底は `exp(−量 / clarity)` の割合で透ける。
      - 深度の読み方は、レンダラーごとの流儀（Compatibility は NDC が −1〜1）に合わせた。
    - **波**: 2方向の値ノイズ（3オクターブ）を動かして、法線を作る。頂点も小さくうねる（`wave_height`）。
    - **屈折**: 波の傾きで、画面の読み取り位置をずらす。ずらした先が水より手前の物なら、ずらさない（手前の物が水に引き込まれない）。
    - **泡**: 水が `foam_width` m より薄い所（岸、岩や杭のまわり）に、ノイズで崩した泡を出す。
    - **反射**:
      - フレネル（真上からは 2%、浅い角度ではほぼ全部）。
      - 自前の画面空間反射: 28歩で、深度バッファに当たるまで進む。画面の端ではフェードする。
      - 当たった所では、空の映り込み（specular）を弱めて、二重にならないようにした。
    - 底の色は emission で出す。ライトで二重に照らされないようにするため。
  - 既存の `MATERIAL_WATER` は変えていない（互換）。
- **ツール**:
  - `look water --scene [--position] [--size x,z] [--shallow] [--deep] [--clarity] [--waves] [--wave-scale] [--wave-speed] [--swell] [--foam] [--refraction] [--reflection]`
  - MCP: look_water。
  - `uzu.py selftest engine` に2項目を足した（水を置いてシーンに保存される、色の誤りを断る）。
- **見本**: `ai_loop/look_samples/water/`（make_samples.py で生成、水はなし）。
  - 池の構成: 底は、手前の岸（z = 3、y = 0.15）から奥（z = −15、y = −3）へ傾く。底の上に明るい帯がある。
  - 水の中に、赤い杭と岩3つ。奥の岸に、白い塔。
  - `shoot_all.sh` に water_default／water_surface／water_golden を足した。
- ドキュメント: UZULook.xml に add_water と create_water_material を追加した。

## 限り（正直な前提）

- 水面は水平が前提（波の法線は世界の上向きに対して作る）。斜めの水（滝）は対象外。
- 画面空間の反射なので、画面の外にある物は映らない。代わりに、空と反射プローブが見える。
- 光の模様（コースティクス）、流れの向き、水中のカメラは入っていない。必要なら別の項目にする。
- GPU での見た目と速さ（28歩の反射＋ノイズの費用）の確認は、ローカル担当。
