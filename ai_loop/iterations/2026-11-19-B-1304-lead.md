## 実装

新規クラス `UZUUIJuice`（`scene/gui/uzu_ui_juice.{h,cpp}`、`GDREGISTER_ABSTRACT_CLASS`、
ドキュメント `doc/classes/UZUUIJuice.xml`）。UZUJuice（B-1101〜）と同じ流儀:
静的 API＋初回利用時にシーンルートへ自動生成されるランタイムノード
`UZUUIJuiceRuntime`（PROCESS_MODE_ALWAYS）が毎フレーム進める。アニメーションは
純粋な状態値（経過時間／duration を名前つきカーブに通す）で決まるので、
実時間待ちなしに単体テストで固定できる。対象 Control の scale／pivot／modulate は
開始時に捕捉し、終了・キャンセル時に正確に復元する。静的なテクスチャキャッシュは
持たない（終了時クラッシュの教訓）。

### 動きの語彙（名前で選べるプリセット）

出典は gameanimation.info「UIの細かい動き」（2026-11-19 オーナー共有）。

| プリセット | 意味 | 実装 |
|---|---|---|
| anticipation | 予備動作: 本動作の逆を先に入れる | 最初の30%で −0.18×strength まで沈み、残りは ease-out cubic |
| overshoot | 目標を超えて戻る（強さ段階つき） | back-out。`overshoot_value(t, level)` level 1/2/3 = 定数 0.8／1.70158／2.8。strength は定数を倍率で拡縮 |
| ease_in | 機械的に減速して止まる（記事のスローイン） | ease-out cubic。目標を超えない・単調 |
| bounce | 跳ねて収束（稀用） | 標準 ease-out bounce（4弧） |
| step | コマ落とし（ピクセル世界用に追加） | 4フレーム保持の量子化 |

全カーブで両端は正確（t=0 → 0、t=1 → 1）。`get_preset_names()`／`get_preset(name)`
で名前と既定値（duration／strength、overshoot は `overshoot_by_level`、step は `steps`）
がデータとして引ける。

### 操作 API

- `open_panel(control, preset="overshoot", duration, strength)`: 表示してカーブで拡大。
- `close_panel(control, preset="anticipation", ...)`: 既定の予備動作で一瞬膨らんでから縮み、最後に隠す。
- `hover_pulse(control, strength, duration)`: ホバー／押下用の一発の膨らみ（+10%×strength → 正確に復元）。
- `count_up(control, from, to, duration, preset, strength)`: Label のテキスト／Range の値をカーブで数え上げ、最終値は正確。
- `transition(from, to, duration, preset, strength)`: 画面遷移の最小版（旧画面フェードアウト＋隠す、新画面フェードイン）。
- `apply_world_motion(control, world, open)`: B-1307 第1段の `UZUUI::get_world_motion(world)` を読む薄い連携。steps>0 → step、overshoot>0 → overshoot（世界の値を back 定数として strength に換算）、それ以外 → ease_in。UZUUI 側は変更していない。
- 状態・記録: `is_animating`、`get_active_animation_count`、`cancel`／`cancel_all`、
  `get_event_log`／`clear_event_log`（開始・終了ごとに {event, phase, preset, target} を記録、最新256件）。
  自己検証プレイ側はこのログで UI イベントの発火を確認できる（BACKLOG の判定）。
- `apply_animations(dt)`: ランタイムが毎フレーム呼ぶ進行関数。テストもこれを固定ステップで直接呼ぶ。
  `motion_value(preset, t, strength)` は純粋関数として公開。

## テスト

`tests/scene/test_uzu_ui_juice.cpp`（新規8ケース）: 語彙の名前とプリセットデータ、
カーブの性質（両端・overshoot の超過と段階・ease_in の単調性・anticipation の沈み・
bounce の到達・step の保持）、開閉（overshoot で目標超過→正確復元、anticipation で
膨らんでから隠れる）、ホバー、カウントアップ（Label と ProgressBar、overshoot で
目標超過→正確着地）、画面遷移、世界モーション（persona=overshoot／pixel=step／
sf=ease_in、未知の世界は false）。実時間待ちは使わず `apply_animations` の固定
ステップで判定する。ツリー内のノードはテスト中に消していない（対象はツリー外の
Control のみ、UZUUI のテストと同じ流儀）。
