# B-726 の GPU 再確認 — Claude Code ローカル（Windows、RTX 4050、2026-11-18）

ai-native e552c2379a（B-725 の PR #5、B-726 の d1d77b824f を含む）をビルドし、見本 hd2d で Vulkan で撮った。道具は `ai_loop/windows/sprite_shadow_variant.gd`（base と no_blob）。

## 結論: 判定はすべて満たした

| 場面 | BlobShadow（保存された値） | 胴の帯（あり／なし） | 地面が暗くなった画素（6 以上） | 最大の暗さ |
|---|---|---|---|---|
| B-725 前の再確認（参考） | size 0.2×1×0.2、板の中心 | 30.5 → 5.4 | 0（差分なし） | 0 |
| 見本の写しに新しく `look hd2d` | size 0.768×1×0.768、y −0.72（足元）×3 | 5.4／5.4 | 4182 | 28 |
| 古い影（0.2、板の中心）が保存された場面に再適用 | 同上に直った、3 個のまま（重複なし） | 3.8／3.8 | 4186 | 28 |

- **地面に丸い影が出た。** BlobShadow ありとなしの差は、3 人の足元の地面だけ（範囲 758,591–1143,770）。
- **胴の帯は戻っていない。** どちらの場面でも、BlobShadow ありとなしで胴の値が同じ（影が人物に乗っていない）。再適用した場面の 3.8 は、5.4 より小さく、帯の判定の範囲内。
- **再適用で直る。** B-725 の確認で保存された古い場面（size 0.2、transform なし）に `look hd2d` をもう一度かけると、3 個の Decal がその場で足元・正しい大きさに直り、増えなかった。
- **全テスト pass（Windows）:** 1500 件 pass、失敗 0、スキップ 3（クラウドより 6 件少ないのは UDSServer のテストが UNIX 専用のため）。
- **見本の保存済みの影の作り直し:** リポジトリの `ai_loop/look_samples/hd2d/main.tscn` には BlobShadow が保存されていない（`look hd2d` を当てた写しにだけできる）。そのため、作り直すものはなかった。
