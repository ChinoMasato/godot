# iterations — イテレーション記録（エージェント別）

マルチエージェント開発では `LEDGER.md` への追記を統合担当に集約するため、各エージェントは自分のイテレーション記録をここへ **1イテレーション1ファイル** で置く。

ファイル名: `<YYYY-MM-DD>-<項目ID>-<担当名>.md`（例: `2026-11-17-B-101-claude-a.md`）

書式:

```md
# <項目ID> <タイトル> — <担当名> (<日付>)

- ブランチ: agent/<...>
- 変更概要: （何を、なぜ）
- 変更ファイル: （主なもの）
- テスト結果: 増分ビルド / 全テスト pass・fail の内訳
- 失敗と理由: （あれば。差し戻した場合はその判断も）
- 申し送り: （共有ファイルを触る必要があった、競合した、等）
```
