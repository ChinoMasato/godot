# B-904 Picture CLI 信頼性補完 — Codex local、2026-11-18

対象: ai-native 3c5f83c131 の Python 試作入口。C++化・本体の公開APIは変更せず、AIが処理結果を正しく扱えるようにした。

## 修正

- `doctor` を追加。バイナリ・project.godot・ツールスクリプト・Pillow・バージョン・タイムアウトをJSONで診断する。描画もモデル推定も実行しない。
- 実行するGDScriptを対象プロジェクト内ではなく、同梱ツールの絶対パスで指定。素材だけを持つ別プロジェクトでも map／PBR／設定コマンドを使える。
- Windowsのconsoleラッパーより実行本体を優先。起動失敗、異常終了、ERROR、タイムアウト、欠落／壊れた／複数のJSON結果を成功扱いしない。
- `ok` は真偽値を要求し、入力エラーの `problems` などは構造を保持する。
- 既定120秒で打ち切り。自分が起動したプロセスツリーを終了し、OS側で終了に失敗したときはcleanup_warningを返す。
- `shot` はfpsと時刻を先に検査。指定時刻のフレームが無い場合、最終フレームで代用せず missing_frames を返す。PNGを全部検査してから公開し、Pillow欠落時に存在しないmotion.pngを返さない。
