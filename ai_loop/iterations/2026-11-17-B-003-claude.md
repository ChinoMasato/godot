## version.py の2項目の行き先

| 項目 | 現在値 | 生成されるマクロ | 使われ方 |

## short_name を変えた場合の影響（互換に影響あり）

`OS::get_godot_dir_name()` が short_name から作られる（Linux などは小文字、Windows／macOS は先頭大文字）。
- **ゲームの `user://`**: `core/os/os.cpp:347,350`。`<データ dir>/godot/app_userdata/<アプリ名>`。変えると既存プロジェクトのセーブデータや設定が「消えたように見える」。`project_list.cpp:878,881` のプロジェクトマネージャ表示も同じ。（`use_custom_user_dir` を使っているプロジェクトは影響なし）
- **エディタの設定・データ・キャッシュ**: `editor/file_system/editor_paths.cpp:185,188,194`。Linux なら `~/.config/godot`、`~/.local/share/godot`（**書き出しテンプレートの置き場所を含む**）、`~/.cache/godot`。変えるとエディタ設定・テンプレート・最近のプロジェクト一覧が引き継がれない。逆に言えば、本家 Godot と U.ZU Engine が同じディレクトリを共有しなくなる（混在環境では利点にもなる）。
- **C#（mono）の設定パス**: `modules/mono/godotsharp_dirs.cpp:75`。
- **アセットライブラリの表示**: `asset_library_editor_plugin.cpp:1902`（文言だけ）。
- **ビルドシステム**: `methods.py:267` の `is_engine()` が、version.py に文字列 `short_name = "godot"` があるかでエンジンのソースツリーを見分けている（`custom_modules` で再帰的に探すときに、エンジン自身を除外するため）。変えると、この判定が効かなくなる。直すなら methods.py にも手が入る。

影響しないもの: 実行ファイル名（`bin/godot.*` は SConstruct 側で固定）、プロジェクト形式（.tscn／.gd／.tres／project.godot のファイル名と中身、`.godot/` ディレクトリ）。

## name を変えた場合の影響（表示だけ。互換への影響は小さい）

`GODOT_VERSION_NAME` の使用箇所は 22。
- エディタ・プロジェクトマネージャのウィンドウタイトル、起動ヘッダ（`main.cpp:388-396`）、project.godot のファイルダイアログのフィルタ表示。
- 外部に見える識別名: Vulkan の `pEngineName`、PulseAudio のコンテキスト名、Windows の OpenGL ドライバのアプリプロファイル名（`gl_manager_windows_native.cpp:175`。ドライバ側の Godot 向けプロファイルが効かなくなる可能性あり）、Android 書き出し時の既定アプリ名（`export_plugin.cpp:516`）。
- マテリアル→シェーダ変換で生成されるコードの先頭コメント（`// NOTE: Shader automatically converted from Godot Engine ...`）。変換後のコメントが変わるだけで、読み込みの互換には影響しない。
- 単体テストは、これらの名前を直接参照していない（tests/ を検索して該当なし）。

## BACKLOG の判定条件について（要確認）

B-003 の判定に「--version の表示が U.ZU Engine になること」とあるが、`--version` は `get_full_version_string()`（例 `4.8.beta.custom_build.3d70ab368`）しか出さず、name も short_name も含まない（`main.cpp:1178-1179`）。version.py を変えるだけでは判定を満たせない。代わりに使える判定は「起動ヘッダ（`--headless --quit` で出る1行目）が U.ZU Engine になること」。--version 自体に名前を出すなら main.cpp の変更（出力形式の変更）になる。

## 提案（オーナー判断）

- 案A（推奨）: **name だけ "U.ZU Engine" に変え、short_name は "godot" のまま**。表示は U.ZU Engine になり、ユーザーデータ・エディタ設定・テンプレート・ビルド判定の互換を保てる。判定は「起動ヘッダの表示」と「全テスト pass」に置き換える。
- 案B: short_name も変える（例 "uzu_engine"）。本家 Godot とディレクトリを分けられるが、既存データの引き継ぎ（移行処理か手動コピーの案内）と、methods.py の `is_engine()` の修正が要る。設計判断になる。
- 補足: 「Godot Engine」は商品名なので、name の変更は MIT のライセンス表記とは別の話（著作権表記は変えない）。
