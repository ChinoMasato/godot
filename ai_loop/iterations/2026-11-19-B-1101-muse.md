## したこと
- `UZUJuice`（scene/3d/uzu_juice.{h,cpp}、Object＋静的 API）を新設。`hitstop(duration, scale=0)`、`slowmo(scale, duration)`、`cancel_time_effects()`、`is_time_effect_active()`、`applied_time_scale()`。

- 駆動は初回利用時に SceneTree ルートへ自動生成される `UZUJuiceRuntime` ノード（PROCESS_MODE_ALWAYS、NOTIFICATION_PROCESS で毎フレーム再計算）。シーン遷移を生き延びる。
- 単体テスト5件（tests/scene/test_uzu_juice.cpp）: 待機／ヒットストップの持続と復帰／重なりの優先と再開／基準速度の保持／静的 API。

## Godot 4.8 master の API 注意（今回 CI で踏んだもの）
- Time は `core/os/time.h`（core/time/time.h は無い）。
- Node の `_process` / `_notification` は C++ の virtual override ではない。`void _notification(int)` を宣言し、コンストラクタで `set_process(true)`。
- `SceneTree::get_root()` は `RequiredResult<Window>` を返す。`Window *root = tree->get_root();` と受け、`scene/main/window.h` が要る。
- `get_node_or_null` へ文字列リテラルを直接渡せない。`NodePath("...")` で包む。
- ClassDB / D_METHOD / DEFVAL は `core/object/class_db.h` を明示 include。
