# B-1512 生成器の自己申告バグ修正（2026-11-20、Muse lead branch）

B-1511 の再読監査が発見した生成器の自己申告バグの修正。ブランチ

## 修正箇所

- `modules/uzu_worldgen/uzu_world_gen.cpp:2832`:
  `frames_total * frame_mesh->get_faces().size() / 3` → `/ 3` を削除。
  C++ の `Mesh::get_faces()` は Face3（三角形そのもの）の配列を返すので
  `.size()` は既に三角形数であり、`/ 3` が二重割り算だった
  （B-1511 の算術: 申告 6746 = 3984 + 37×224/3 の切り捨て 2762、
  実物 12272 = 3984 + 37×224）。

## 同種誤りの有無

uzu_worldgen 内を grep で全数確認し、二重割り算は上記の1箇所のみ:

- `get_faces().size()` の使用は 2832 行だけ（他に `get_faces` 自体の
  使用なし）。
- 他の `/ 3` はいずれも正しい割り算: `MeshBuilder::triangles()` の
  `verts.size() / 3`（443 行、頂点配列に対する割り算）、重心計算の
  `(a + b + c) / 3.0f`（553 行）、テクスチャ模様・列数の計算
  （1780／1784／2234／2359 行）。
- `terrain_triangles = n * n * 2`（1476 行、格子地形）は正しい。
