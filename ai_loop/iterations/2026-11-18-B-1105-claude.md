## 内容

- **エンジン**（`scene/resources/uzu_sfx.{h,cpp}`、新規）: `UZUSfx`（静的メソッドだけのクラス）。UZUJuice とは別のクラスにした。B-1106 の `UZUJuice.impact` から呼べる。
  - `generate(params)`: 16 bit モノラルの AudioStreamWAV を返す。パラメータは次のとおり。
    - 波形: square／saw／sine／triangle／noise。
    - 音程:
      - `frequency` → `frequency_end` へ、オクターブで均等に滑る。
      - `change_ratio`／`change_time`: 途中で音程が跳ぶ（コインの音）。
      - ビブラート（深さは半音、速さは Hz）。
    - 矩形波の duty と、その時間変化。
    - 包絡: attack／sustain／decay と、punch（sustain の頭を強める）。
    - 1極のローパス。音量、ノイズの seed、サンプルレート。
    - 知らないパラメータ、知らない波形、長さ 0 か 10 秒超は、誤りで null を返す。
  - プリセット9種: hit、jump、pickup、coin、explosion、laser、powerup、blip、land。
    - `get_preset(name, seed)`: seed 0 はプリセットそのもの。ほかの seed では、音程が ±0.2 オクターブ、長さが ±15% だけ変わる（同じ seed なら同じ音）。
    - `generate_preset(name, seed)` も用意した。
  - `describe(stream)`: 聞けないエージェントのための「耳」。返す値は次のとおり。
    - 長さ、ピーク、RMS。
    - 最初と最後の1/5の、ゼロ交差数／秒（音なら音程のほぼ2倍）。
    - `ends_silent`: 最後の 1 ms がピークの 5% 未満（終わりにプツ音がない）。
  - `play(parent, stream, pitch_jitter = 0.05, volume_jitter_db = 1, volume_db = 0)`: 1回だけ鳴らす AudioStreamPlayer を足す。ピッチと音量はランダムに少し変わり、鳴り終わると自分で消える。
  - 登録した。ドキュメント `doc/classes/UZUSfx.xml`（新規）も追加した。
- **ツール**:
  - `engine sfx --out res://sfx/x.wav [--preset] [--seed] [--set '{...}']`: WAV を保存し、describe の結果を返す。
  - `engine sfx-presets`
  - MCP: sfx_make、sfx_presets。
  - `uzu.py selftest engine` に3項目を足した。

## 確認

- 単体テスト: `tests/scene/test_uzu_sfx.cpp`（新規、5件）。
  - `[Audio]` を付けた。テストの仕組みが、ダミーの AudioServer を作る（AudioStreamWAV の set_data が AudioServer を使うため）。
  - **sine 440 Hz の音**:
    - 長さ 0.31 秒、ピーク 0.8 は指定どおり。
    - ゼロ交差 880/秒（±3%）。
    - 終わりは無音。
  - **滑り・跳び・ノイズ**:
    - 200→800 Hz で、終わりの音程が始めの2倍を超える。
    - 跳び（×2）で、終わりの音程が始めの2倍（±8%）になる。
    - ノイズは交差が多く、ローパスで減る。
  - **プリセット**:
    - 9種がそろい、すべて 0.02〜1.5 秒、ピーク 0.2〜1.0、終わりは無音。
    - jump は上がり、laser は下がる。
    - 同じ seed なら同じデータ、別の seed なら別のデータ、seed 0 はプリセットそのもの（変化は ±0.2 オクターブ以内）。
  - **誤り**: 知らないパラメータ、知らない波形、長さ 0、知らないプリセット。
  - **再生（20回）**:
    - ピッチ 0.9〜1.1、音量 −8〜−4 dB の範囲に入る。
    - autoplay で、finished で消える。
    - null の親と null の音は断る。
    - 親はツリーの外に置いた（テストでは実際には鳴らさない）。
