# B-201 構造化エラーログ（--log-json） — claude (2026-11-17)

- ブランチ: ai-native に直接反映（オーナーの「即反映で良い」による）。
- BACKLOG B-201: エンジンのエラー／警告を、オプトイン指定時に JSON Lines で出す。既存の通常出力は変えない。

## 内容

- `core/error/error_log_json.{h,cpp}`（新規）: エンジンのエラー処理（`add_error_handler`）に登録するハンドラー。エラーと警告を、1件ずつ JSON の1行でファイルに追記する。
  - 項目: `level`（error／warning／script_error／shader_error）、`code`、`file`、`line`、`function`、`message`、`condition`。
  - `code`: 「E」＋8桁の16進数。ファイル・関数・条件（チェックした式）から作るので、同じ発生箇所なら実行ごと・行番号が変わっても同じになる。メッセージは値が入って変わりやすいので使わない。パスの区切り（\ と /）の違いも吸収する。
  - スレッドの排他（Mutex）あり。ログの書き込み中に起きたエラーで再帰しないようにしてある。
- `main/main.cpp`: コマンドラインに `--log-json <file>` を追加（ヘルプにも記載）。ファイルシステムが使えるようになった後で開始し、終了処理（cleanup と test_cleanup）で止める。指定しなければ何も変わらない。
- `ai_loop/engine.sh run`: 実行時に `--log-json` を使い、errors を構造化された JSON（level・code・file・line・function・message）で返すようにした。self-test も構造化された結果を確かめるように更新した。
