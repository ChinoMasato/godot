# B-1201 Blender ブリッジ — Codex

ベースは `24a2621591`。外部 Blender で素材の Python スクリプトを実行し、プレビュー PNG と GLB を Godot プロジェクトに置く単独コマンド `ai_loop/blender_bridge.py` を追加した。空のシーンに素材を作り、プレビュー用に置いたカメラ・ライトは GLB から除く。モディファイアは書き出した形状に反映する。見本と手順は `ai_loop/blender/`。

2ファイルを先に一時ディレクトリで生成し、出力名が空いていることを確認してから配置する。既存の GLB／PNG を上書きしないよう、完成ファイルをハードリンクで配置する。このため配置先にハードリンク対応のファイルシステムが必要。

## 確認

- Linux の Blender 4.3.2 で自作の木箱を生成。空白を含むプロジェクト名と素材名で、GLB 77,884 bytes、PNG 164,058 bytes。
- 新しい U.ZU editor でヘッドレス取り込みを実行。GLB をシーンとして読み込み、メッシュ10個とその StandardMaterial3D、撮影用カメラ・ライト各0、プレビュー384×384を機械判定した。
- 同じ出力名、プロジェクト外を指すパス、例外を出す素材スクリプトは拒否した。既存ファイルのハッシュは変わらず、例外の出力ファイルも残らない。
- 最初の試走では、この Blender の Cycles がデノイズに対応せず失敗した。見本だけデノイズを切り、PNG と GLB の生成、取り込みまで再実行して成功した。
- ロック付き Linux editor のビルドは39.47秒。全単体テスト1523 pass、0 fail、3 skip。538882 assertions pass。Ruff と `py_compile` も成功。
