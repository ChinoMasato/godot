JSON コマンドの終了コードはエンジンの終了コードを維持する。既知の環境起因失敗を自動除外しない。
したがって、終了コードが非ゼロでも JSON は確認すること。JSON の読み取りを `&&` の後に置かない。
レポート欠損・破損・集計不一致は終了2で stderr に理由を出し、正常そうに見える JSON は出さない。
`skipped` にはフィルターで除外されたケースも含まれる。マージ判定時はフィルターなしの全件結果を使う。
