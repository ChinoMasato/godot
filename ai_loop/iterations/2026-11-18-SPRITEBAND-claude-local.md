# HD-2D の人物の胴に出る縦の暗い帯の原因 — Claude Code ローカル（Windows、RTX 4050、2026-11-18）

HD2D-GPU と B-723/B-724 の記録で「記録のみ」にしていた小件の切り分け。エンジンのコードは変えず、`look hd2d` を当てた見本 hd2d の写しで、1 つずつ設定を変えて GPU で撮った（バイナリ 8df1b6986）。

## 結論

- **胴の縦の帯の原因は、足元の丸い影（B-716 の `BlobShadow`、Decal）が人物の板そのものにも投影されていること。** 影（シャドウマップ）ではない。
  - 手前の人物（Hero3）の胴の青い部分で、列ごとの明るさの最大と最小の差: そのまま **30.5** → BlobShadow を外すと **5.4**。暗さの形は、真ん中が最も暗い左右対称（Decal の放射状のグラデーションと同じ形）。
  - 影の設定を変えても、この形はまったく同じだった（スプライトが影を落とさない、太陽の影を切る、shadow_bias 0.5、normal_bias 4.0）。SSAO／SSIL／SSR／グロー／霧／チルトシフトを全部切っても残った。backlight 0 でも残った。
  - Decal の `cull_mask` が全レイヤー（1048575）のままで、高さ 1 m の箱が人物の下半分を含むため、人物にも暗い円が乗る。テクスチャの胴は一色（明るさ 106）で、絵のせいではない。
- **真ん中の人物（Hero2）の顔から胴にかかる暗い斜めの部分は、手前の人物（Hero3）が落とす影。** 不具合ではない（B-716 の「影を受ける」どおり）。
  - Hero2 の顔の明るさ: そのまま 64.8、スプライトが影を落とさない 86.9、Hero3 だけが影を落とす 64.8、Hero／Hero2 だけが影を落とす 86.8／86.9。
  - ただし、カメラを向いた板の影なので、板に落ちると形がわかりにくい。気になるなら、スプライト同士では影を受けない設定も選べる（判断はオーナー）。

## 直し方の案（B-716 の BlobShadow。クラウド担当の scene/ のコード）

1. Decal の `cull_mask` からスプライトのレイヤーを外す（例: `configure_lit_sprite` でスプライトを専用のレイヤーに置き、`create_blob_shadow` の Decal はそのレイヤーを除く）。人物には乗らず、地面だけが暗くなる。
2. または、Decal の箱を低くする（高さを 0.1〜0.2 m 程度にして地面だけを含める）。ただし足元はまだ少し暗くなる。

推しは 1。判定案: hd2d の見本で、BlobShadow ありとなしの胴の列の明るさの差がほぼ同じ（いまの 5.4 前後）になり、地面の丸い影は残ること。
