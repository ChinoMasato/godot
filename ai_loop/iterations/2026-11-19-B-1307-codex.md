# B-1307 画像生成を使ったゲーム内 UI 見本 — Codex

オーナーの提案を受け、夕暮れの村と藍×真鍮の会話枠を画像生成し、独立した Godot 見本 `ai_loop/look_samples/lantern_ui/` に組み込んだ。枠を9分割で伸縮させ、日本語・ボタンの状態・会話の進行は Godot の Control で実装。既存素材からサブセットした日英フォントとライセンスを同梱した。生成画像2枚を WebP に変換し、画像・フォントで約246 KiB。

- Godot の Compatibility OpenGL（Mesa llvmpipe）を使い、1152×648 と390×844で撮影した。L/R 余白、会話の折り返し、ボタンと本文が画面内に収まることを確認。
- 同じ2解像度でフォーカスしたボタンに Enter を送り、会話が進むことを確認。ボタン座標へのマウス入力で会話を閉じ、開き直せた。検証スクリプト `verify.gd` は同梱済みで、2解像度とも `UI_RESULT.ok=true`。
- サンプルの実描画は `70d2d05d6d` の配布バイナリを使った。ベースは `362cf118c1`。成果物は独立サンプルで、既存テーマやエンジンの C++ を変更していない。
- 画面画像とログは `/workspace/artifacts/b-1307/`。統合はリードに引き継ぐ。
