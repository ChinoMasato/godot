# B-1307 画像生成を使ったゲーム内 UI 見本 — Codex

オーナーの提案を受け、夕暮れの村と藍×真鍮の会話枠を画像生成し、独立した Godot 見本 `ai_loop/look_samples/lantern_ui/` に組み込んだ。枠を9分割で伸縮させ、日本語・ボタンの状態・会話の進行は Godot の Control で実装。既存素材からサブセットした日英フォントとライセンスを同梱した。生成画像2枚を WebP に変換し、画像・フォントで約246 KiB。

- Godot の Compatibility OpenGL（Mesa llvmpipe）を使い、1152×648 と390×844で撮影した。L/R 余白、会話の折り返し、ボタンと本文が画面内に収まることを確認。
- 同じ2解像度でフォーカスしたボタンに Enter を送り、会話が進むことを確認。ボタン座標へのマウス入力で会話を閉じ、開き直せた。検証スクリプト `verify.gd` は同梱済みで、2解像度とも `UI_RESULT.ok=true`。
- サンプルの実描画は `70d2d05d6d` の配布バイナリを使った。ベースは `362cf118c1`。成果物は独立サンプルで、既存テーマやエンジンの C++ を変更していない。
- 画面画像とログは `/workspace/artifacts/b-1307/`。統合はリードに引き継ぐ。

## 会話の動きの追加

- `UZUUIJuice` の和風モーションで会話枠を開閉し、ボタンはホバー・キーボードフォーカス・押下に短い反応を返す。開閉中の重複操作はページを進めない。光のレイヤーを背景画像の祠に合わせ、ゆっくり明滅させる。
- `--reduce-motion` では開閉とボタンを即時に動作させ、灯りは固定する。会話を進める、閉じる、開き直す操作は同じ。
- `10496a91f0` でビルドされた [Actions 44445056884](https://github.com/ChinoMasato/uzu-engine/actions/runs/44445056884) のバイナリを SHA-256 で照合し、同ベースのテストデータと全単体テストを実行した。1558成功・0失敗・3スキップ、540525 assertions 成功。
- 同バイナリの実描画で横長1152×648、縦長390×844、縦長の動き軽減の3条件が成功。通常モードでは開2組・閉1組とボタン反応の開始／終了、灯りの変化を確認。動き軽減ではイベント0件、光量が固定でもキーとクリックの操作が通った。
- Godot で開閉を撮影した58フレームの GIF は `/workspace/artifacts/b-1307/dialogue-motion.gif`。操作ログは `verification-summary.log`。適用範囲は独立した見本。
