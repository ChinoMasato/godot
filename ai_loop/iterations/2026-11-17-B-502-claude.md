## 内容

- `ai_loop/prepublish.py`（新規、標準ライブラリだけ）
  - `check <ビルドのフォルダー | zip> [--max-mb 500] [--max-files 1000]`: 1行の JSON を出し、問題があれば終了コード 1。調べる問題は4つ。
    - `engine_license_missing`: エンジンの MIT ライセンスがない。「エンジンの著作権表示の行（リポジトリの LICENSE.txt の1行目）」と「許諾文」の両方を含むファイルがなければこの問題になる。MIT ライセンスでは同梱が条件。
    - `third_party_notices_missing`: 第三者ライブラリの表記（エンジンの COPYRIGHT.txt。debian/copyright 形式で、Files: の項が並ぶもの）がない。同梱しているライブラリのいくつかが、表記を条件にしている。
    - `too_large`: サイズが上限を超えた。既定は 500 MB。itch.io の1アップロードの上限は 1000 MB だが、ブラウザーゲームはずっと小さくしたいので半分にした。
    - `too_many_files`: ファイル数が上限を超えた。既定は 1000（itch.io の HTML5 の上限）。
  - `add-notices <ビルドのフォルダー>`: LICENSE.txt と COPYRIGHT.txt を、`ENGINE_LICENSE.txt`／`ENGINE_COPYRIGHT.txt` としてビルドに入れる。足りないと言われたときの直し方として、check のメッセージにも書いた。
  - 探すのはテキストのファイル（拡張子なし・.txt・.md・.html）だけで、4 MB を超えるものは読まない。本文で判定するので、ファイル名は何でもよい。

## 確認

- `prepublish.py --self-test`: ok。
  - 表記が漏れたテスト用ビルド（pck と README だけ）: 2つの問題で fail した。
  - add-notices の後: pass。
  - 上限を下げると、サイズとファイル数のそれぞれで fail する。
  - LICENSE だけで COPYRIGHT がないと fail する。
  - zip のビルドも同じように調べられる。
- 全テスト: C++ の変更はないので、B-103 と同じバイナリで 1481/1481 pass。
