- 「環境起因」と判断した根拠:

  3. 対照実験: /etc/hosts に `::1 localhost` を一時的に足すと、該当テストは 2000 assertion すべて pass し、全件実行でも test cases 1431／pass 1431／fail 0／skip 3（assertion 423591 すべて pass）になる。実験のあと /etc/hosts は元に戻した。
  4. 同じ IPv4 の解決（127.0.0.1）は同じテスト内で pass している。fail したのは OS の名前解決に IPv6 の localhost が無い部分だけ。
- 結論: コード起因の失敗は 0 件。
