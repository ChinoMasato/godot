# B-727 水面の GPU 比較手順 — Codex

`ai_loop/windows/water_gpu.py` は既存の水の見本、`uzu.py look apply / water`、`scene_time.gd` を使う。カメラ・照明・解像度を揃え、水なし、既定の水、画面空間反射だけ無効にした水を撮影する。PNG、エンジンログ、GPU 時間の中央値と95パーセンタイルを保存する。使い方は `ai_loop/windows/water_gpu.md`。

## 検証

- ベースは `e450f2db74`。B-110 の Actions でビルドした `7ad07707a8` の配布バイナリを再利用した。両コミット間にエンジンソースやテストデータの差分はない。
- Vulkan Forward+ と Mesa llvmpipe の実行で3ケースとも撮影と計測に成功。640×360、各60フレームの準備後に12フレームを採取。GPU 時間の中央値は水なし116.129ms、既定水面138.308ms、画面空間反射なし127.612ms。水の画像に浅瀬と深部の色の差、杭や岸の泡、塔の反射を確認した。時間はソフトウェア描画での試走結果。Windows GPU の性能判定はローカル担当。
- 初回は準備コマンドの JSON から開き括弧を落として停止した。出力の読み取りを修正し、3ケースを通しで再実行した。存在しない実行ファイルでは JSON の失敗レポートと非0終了を確認した。
- 配布 ZIP 直下の実行ファイルだけで全テストを試すと、隣接する `tests/data` が無く失敗する。checkout の `bin/` にこの同じバイナリを置いた対照では **1515 pass、0 fail、3 skip**（531644 assertions pass）。通常の起動や撮影には配布 ZIP の実行ファイルを使える。
- Ruff check、format check、`py_compile`、`git diff --check` は成功。
- ログ・PNG・レポートは `/workspace/artifacts/b-727/software-v2/`。Windows 実行前に、出力先へ新規ディレクトリを指定する。
