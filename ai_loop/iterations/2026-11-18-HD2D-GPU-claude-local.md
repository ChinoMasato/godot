## 見た目（GPU）

よい点: 望遠の見下ろしと帯ぼかしでジオラマ感が出る。人物の影が地面と柱に落ちる（柱の上の影はドット絵の形）。テクセルはくっきり、1.25 倍だった人物もそろう。火の粉と蛍はグローでにじんで光る。

### 不具合1: 人物の頭の上に横線が出る（B-716 の輪郭）

- 頭の 1 テクセル上に、頭より幅の広い黒い横線が出る（`hd2d_gpu_outline_wrap.png`）。3 人とも同じ。
- 原因: 輪郭のシェーダーが、上下左右の隣を `texture(sprite_texture, UV ± step)` で読む。サンプラーが折り返し（repeat）なので、透明な最上段（0 行目）の「上の隣」が最下段（23 行目、靴）になる。そこが不透明なので、最上段に輪郭が塗られる。
  - hero.png の 0 行目は全部透明、1 行目は髪（6〜9 列）、23 行目は靴（4〜6、10〜12 列）。線の幅は、この二つを合わせた幅と一致する。
  - 同じ理屈で、最下段の下や左右の端にも出うる（見本では最下段が不透明なので目立たない）。
- 直し方の案: `uniform sampler2D sprite_texture : source_color, filter_nearest, repeat_disable;`（normal_texture も同様）。または、UV が 0〜1 の外なら隣を透明とみなす。

### 不具合2: `look hd2d --no-camera` だと人物が逆光で真っ黒になる（B-722）

- 太陽を「カメラの後ろ、40° 横」へ回す処理が、カメラリグの `if (camera)` の中にあるため、`--no-camera` では太陽が回らない。夕方の太陽が人物の後ろに残り、B-716 の backlight（0.5）があっても、ほぼ影絵になる（画像の右中段）。
- 直し方の案: カメラリグをしないときも、今のカメラを基準に太陽を回す。または、回さないことを結果の JSON で知らせる。

### 気になる点（判断はオーナー）

- 人物の胴に、縦の暗い帯が出ることがある（自分の影の可能性。影の描画でもカメラを向く板なので、太陽の向きによっては自分に影を落とす）。小さいので今回は不具合とせず、記録だけにする。
