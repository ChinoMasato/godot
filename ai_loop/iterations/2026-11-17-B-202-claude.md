# B-202 GDScript エラーの JSON 出力（--check-only --json） — claude (2026-11-17)

- ブランチ: ai-native に直接反映。
- BACKLOG B-202: `--check-only` に JSON 出力モードを足す。

## 内容

- `core/error/script_check_json.{h,cpp}`（新規、エディター版のみ）: 検査結果を1行の JSON にする。
  - 出力: `{"ok", "file", "errors": [...], "warnings": [...]}`
  - 各項目: `file`・`line`・`column`・`end_line`・`end_column`・`code`・`message`
  - エラーの `code`: 「GD」＋8桁の16進数。メッセージから、引用符で囲まれた名前と数字を取り除いた残り（文の形）から作る。同じ種類のエラーは、変数名などが違っても同じ code になる。
  - 警告の `code`: 警告自身の名前（`UNUSED_VARIABLE` など）。
- `main/main.cpp`: `--json` を追加。`--check-only --json --script <path>` のとき、スクリプトの言語が持つ検査機能（エディターと同じもの。列番号と、依存先スクリプトのエラーも取れる）で検査する。
  - 検査は通ったのにコンパイルに失敗した場合は、エラー1件として報告する。終了コードは今までどおり（0＝問題なし、1＝エラーあり）。
  - `--json` を付けなければ動作は変わらない。
  - ついでの修正: B-201 で入れた `printerr` の呼び出しを `"%s"` 付きに直した（ビルドの警告 -Wformat-security が出ていたため）。
- `ai_loop/engine.sh check`: `--json` を使い、エンジンが出した JSON をそのまま返す。スクリプトが読み込めないときは code `LOAD` のエラーを1件返す。不要になった文字列の抜き出し処理（errors_json）は消した。MCP の script_check の説明も合わせて直した。
