# B-406 会話とクエストフラグの検証 — Codex

`uzu.py dialogue --spec PATH [--out PATH] [--max-chars N]` と MCP の `dialogue_validate` を追加した。[書き方と実行例](../dialogue/README.md)に沿ってノード、選択肢、フラグの初期値・更新・条件を JSON で宣言できる。検証に合格したグラフは `--out` で書き出せる。

- 同じノードへの合流もフラグ状態ごとに探索する。未到達ノード、選べる行動がなくなる分岐、宣言漏れや未設定フラグの参照、遷移先や型の誤りをコードと JSON 内の位置で報告する。分岐漏れと未設定参照には該当時点のフラグ値が付く。
- 文字数は改行を除く Unicode コードポイントで数え、各表示項目の件数を返す。既定の上限は160文字。
- 今回の対象はデータ作成と検証。ゲーム側で再生する際は `set` をノードへの進入時に適用してから `when` を評価する。
