# B-1106 イベントプリセット impact（2026-11-19、リード）

- API: `UZUJuice.impact(node, kind, power)`（hit／kill／land／pickup／damage）と `get_impact_preset_names()`。部品（ヒットストップ／シェイク／フラッシュ／スクワッシュ／バースト）と UZUSfx の SE を組み合わせ表で発火。
- 検証: CI 全テスト 1540 pass（新規3件）。
- CI 6周の切り分け: テストの include 不足（scene_tree.h／window.h）→ テスト実行時 SIGSEGV。段階 print で `AudioStreamWAV::set_data` 内と特定: set_data は AudioServer を lock するが、テストハーネスは [Audio] タグのケースでしか AudioServer を用意しないため null 参照になっていた。対策2点: (1) impact のテストに [Audio] タグ、(2) UZUSfx::generate に AudioServer 不在時のガード（実バグ修正: 音声サーバーのない道具環境でも落ちない）。
- 教訓: Godot のテストハーネスはタグでサーバー環境が変わる（[Scene]／[Audio]）。エンジン側も singleton 不在を落とさない。
