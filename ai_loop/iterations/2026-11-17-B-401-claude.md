## できること（`ai_loop/engine.sh <project> <command> ...`、結果は JSON 1行）

- シーン（`--scene res://x.tscn`。ノードのパスは root からの相対で、`.` が root）:
  - `new`（シーンを作る）、`tree`（ノード一覧）、`props`（インスペクタに出るプロパティと値）
  - `get` と `set`（`position:y` のような添字つきにも対応）
  - `add`（`--set` で初期値をまとめて指定できる）、`instance`（別のシーンを入れる）、`remove`、`reparent`
  - `call`（メソッドを呼んで戻り値を得る。`--save` で保存）、`connect`（シグナルの永続接続）、`script`（スクリプトを付ける）
- クラス情報: `classes`（`--inherits` で絞る）、`describe`（プロパティ・メソッド・シグナル・定数）。
- 実行と検査（シェル側）:
  - `run`: プロジェクトを指定フレーム数だけヘッドレスで実行し、エラー行とログの末尾を返す。
  - `check`: スクリプトを構文・コンパイル検査し、エラー行を返す（`--check-only`）。
  - `shot`: GPU なしで描画（look.sh と同じ）。
- 値の書き方: Godot のテキスト形式（`1.5`、`"text"`、`Vector3(1, 2, 3)`、`Color(...)`、配列・辞書）。`res://...` はそのリソースを読み込み、`BoxMesh` のようなリソースのクラス名は新しく作る。シーンに埋め込まれたリソースは `{"class": ..., "embedded": true}` で返す。

## self-test（`ai_loop/engine_selftest.sh`）

- 使い捨てのプロジェクトで全コマンドを順に実行し、JSON と保存されたシーンを確かめる。21項目すべて ok（約5秒）。
  - new／add（BoxMesh と位置）／get／set／添字つきの set／reparent（位置が保たれる）／tree／props（埋め込みリソースと位置）／script／call（戻り値 "hello agent"）／connect（.tscn に接続が保存される）／classes／describe／check（正しいスクリプトは ok、壊れたスクリプトはエラーつき）／run（`_ready` の push_error を拾う）／remove。
  - 間違った入力（無いノード、無いシーン）は ok: false。
- 途中の失敗:
  - props がインスペクタに出ない保存専用の項目を基準にしていて、位置（position）が出なかった。インスペクタに出る項目に直した。
  - reparent の後に位置が (0,0,0) になった。編集中のシーンはシーンツリーの外にあり、グローバル座標を保てないため。ローカル座標を保つように直した。
