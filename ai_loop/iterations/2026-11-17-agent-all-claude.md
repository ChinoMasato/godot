## 変更概要

1. **入口を `ai_loop/look.sh` 1つにまとめた**
   - これまでのコマンド: apply／rig／lamp／camera／material（.tres に保存）／info。
   - 追加したコマンド:
     - `shot --out x.png [--frames N]`: GPU なしで描画（screenshot.sh）。
     - `check --image x.png`: 色のバランス・濁り・描き込み密度・構図を JSON で返す（palette_check.py）。
     - `material --kind K --scene S --node N`: プリセットの素材を、シーン内の物に直接割り当てる。
   - これで U.ZU のルック機能（環境・空気・照明・街灯・素材・カメラ・描画・検査）は、すべてこのコマンドから使える。エンジン側からは、スクリプト API `UZULook` でも使える。
2. **構図のチェック**（`palette_check.py`。計画の #19 の、AI 用の部分）
   - 画面を 12×8 に分け、一番描き込みの多い場所（視線の集まる場所の目安）を出す。中心と三分割の交点のうち一番近いものと、その距離を報告する。
   - 一番密な場所が画面の端にあると、ヒントを出す。
   - self-test を2件追加した（三分割の交点の近くを見つける、端にあると警告）。
3. **`UZULook.apply_to_scene` は、既にある太陽も空気に合わせて設定するようにした**
   - サンプルで Night を当てたとき、もともとあった昼の太陽が残り、夜なのに地面が明るかった（下の「見つかった問題」）。
   - 太陽（空を照らす最初の DirectionalLight3D）の向き・色・強さは空気の一部なので、ルックを当てるときに設定し直す（結果は `"sun": "configured"`）。
   - エディタのボタンは従来どおり（太陽が無いときだけ追加）。テストとクラスリファレンスも直した。
4. **B-709 サンプルシーン** `ai_loop/look_samples/`
   - `make_samples.py`: 3つのプロジェクトを書き出す。WorldEnvironment の無い、Godot の初期状態の見た目。
     - landscape: 距離 150〜1400m に重なる山並み、木。空気遠近と遠景ぼかしを見るため。
     - street: 高い建物、人くらいの大きさのカプセル、街灯の柱。照明・夜・レンズを見るため。
     - materials: 葉・肌・ガラス・水と石、逆光。素材を見るため。
   - `shoot_all.sh <out>`: 各サンプルの標準の組み合わせ（10枚）を、エージェントと同じ手順（look.sh）で描画・検査し、`summary.json` にまとめる。エンジンを変える前と後で撮れば、`image_diff.py` で比べられる。約1分。

## 見つかった問題と対応

- 夜の地面が明るい: 上の 3 で修正。修正後の street_night は、暗い中で街灯の周りだけが照らされる。
- 素材のサンプルで、Golden Hour にすると葉の透過光が弱く、葉が暗いままに見える。B-704 の比較（逆光、強さ 1.3、Clear）でははっきり光っていた。低く暖色の太陽では透過光が弱くなるため。バックライトの強さの調整候補として残す（オーナーが見た目で判断する）。
