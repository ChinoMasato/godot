# B-726 BlobShadow 再適用時の再計算 — Muse (lead) (2026-11-18)

- ブランチ: agent/b-726-muse（リードが実装し、Actions 検証後に統合）
- 問題: 保存済みシーンへ見た目を再適用しても、既存の BlobShadow (Decal) は cull mask しか直らず、大きさと位置が古いまま残った。hd2d 見本では、スプライトの矩形が空のときに測られた影（0.2×1×0.2 が板の中心）がそのまま保存され、地面の丸い影が出なかった（B-725 の GPU 再確認で判明）。
- 直し方: `UZULook::add_blob_shadow` が既存の BlobShadow を見つけたら、新規に積まず、その場で大きさ（item_rect × pixel_size から再計算）と足元の位置と cull mask を直して返す。再適用側（apply_to_scene）は両経路とも add_blob_shadow を通る形に統一。
- テスト: 既存の「HD-2D in one call」テストで保存済み影だけ除外されていた形状チェックを全影に広げ、新規テスト「Blob shadow refreshes instead of stacking」（2回呼んでも Decal は1つで、2回目の半径に直る）を追加。
- 検証: GitHub Actions の U.ZU verify が green（2.7分、ビルド＋全テスト）。残り: hd2d 見本の保存済み影の作り直しと、地面の丸い影が測れることの GPU 再確認（ローカル）。この2点が済むまで BACKLOG の B-726 は未完了のままにする。
