# B-1111 音の機械チェック（2026-11-20、Muse / lead branch）

AI は音を聞けない。聞こえ方は機械化できないが、波形の欠陥は数値で捕まえられる。その検査道具を実装した。

## 実装

- **`ai_loop/audio_check.py`（新規、標準ライブラリのみ）**: WAV（PCM 8/16/24/32bit、モノラル／マルチチャンネル、wave モジュール）を読み、検査結果を1つの JSON レポートで返す。検査項目:
  - **levels**: ピーク／RMS（dBFS 併記）。ピーク 0（全編無音）は fail。
  - **clipping**: フルスケール（既定 |v| ≥ 0.999）に張り付いたサンプルの割合と最長連続ラン。割合が上限（既定 0.1%）を超えたら fail。
  - **silence**: 閾値（既定 −60 dBFS）未満のランを列挙し、位置（head／middle／tail）を付ける。最長ランが上限（既定 100 ms）を超えたら fail。
  - **loop_seam**（`--loop` 時のみ）: ループ点の段差 |先頭 − 末尾| を、ファイル自身のサンプル間ステップの p99.9 と比べて判定する（継ぎ目のないループでは段差は通常のステップと同程度になる、というのが根拠）。微分段差も併記。B-1110 のループ判定と共用できる形にしてある。
  - **sprite**（`--manifest` 時のみ）: B-1108 のマニフェスト（engine_tool が書く JSON 形式と、UZUSfx.sprite_manifest の素の辞書形式の両対応）に対し、サンプルレート・総サンプル数の一致、区間の境界と順序、各区間に実際に音があること、区間の前後と先頭・末尾が無音で、ギャップ長が宣言（gap_samples）と一致することを検査する。
  - 同時発音の被りは対象外（再生側ログが要る）と docstring とカタログ説明に明記。閾値は全て引数で変更可能。
- **`uzu.py audio-check <file.wav> [--manifest sprite.json] [--loop] [--out report.json]`**: 接続（docstring＋dispatch）。終了コードは pass=0／fail・読込エラー=1。
- カタログ再生成（229件、cli に audio-check を登録）。テストは selftest tools に登録。

## 閾値の根拠（実測）

UZUSfx プリセット全9件（hit／jump／pickup／coin／explosion／laser／powerup／blip／land、seed 0、他 worktree の既存 editor バイナリで生成）と、9件を束ねた生成スプライト（gap 50 ms = 2205 サンプル、計 141997 サンプル）を実測:

- プリセット: ピーク −6.12〜−2.79 dBFS、RMS −14.66〜−7.98 dBFS、クリッピング 0 サンプル、−60 dBFS 無音の最長ラン 6.1 ms（explosion の末尾）。
- スプライト: 全区間・ギャップ整合 pass。無音最長ラン 51.7 ms（ギャップ 50 ms＋前区間の減衰末尾）。
- 既定値はこの実測に大きな余裕を持たせた（クリッピング上限 0.1% に対し実測 0%、無音上限 100 ms に対し実測最大 51.7 ms はスプライトの意図したギャップ）。

## 反証（変種で検出できること）

- coin を ×4 ゲインでクリッピングさせた変種: フルスケール割合 58.38%、最長ラン 9268 サンプル → clipping fail。
- スプライトのマニフェストで jump の start_sample を +500 ずらした変種: 「ギャップ 2705 ≠ 宣言 2205」「ギャップが無音でない（ピーク 0.5）」→ sprite fail。gap_samples を 2000 と偽った変種も全ギャップ不一致で fail。
- 継ぎ目: 整数周期のサイン／コサインループは pass（段差 0.0114／0.000092）。フェードインを焼いたコサインループは段差 0.6399、末尾 200 サンプルを切ったものは段差 0.8000 → ともに fail。
- 内部に 300 ms の無音を挟んだ hit: silence fail（301 ms）。全編無音ファイル: levels fail。

## 正直な限界

- 継ぎ目検査が見るのはループ点の段差だけ。ファイル中間のクリック（位相反転など）は検出しない（実波形では中間のステップ自体は普通に存在するため、そこは判定対象にしていない）。
- クリッピング判定は「フルスケール到達の割合」なので、ごく僅かなサンプルだけが張り付く軽いオーバーゲインは既定 0.1% では素通りする。生の割合はレポートに残るので、厳しく見たい側は閾値を下げられる。
- 無音判定は一律のレベル閾値。−60 dBFS 未満の静かな導入が 100 ms 以上続く BGM は意図的でも fail する（閾値は引数で緩められる）。
- ラウドネスはピーク／RMS のみで、知覚重み付け（LUFS 等）はしていない。聞こえ方そのものは当然測れない。
- スプライト検査は gap_samples が宣言されている場合のみギャップ長を照合できる。宣言が無いマニフェストでは「ギャップが無音か」「区間に音があるか」まで。
- 実フィクスチャは 16bit のみ（UZUSfx の出力形式）。8/24/32bit の復号経路は実装したが実物での確認はしていない。
