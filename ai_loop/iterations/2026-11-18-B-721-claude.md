# B-721 パレット量子化＋ディザリング — claude (2026-11-18)

- ブランチ: ai-native に直接反映（リードの着手順。HD-2D の合間の小物）。
- BACKLOG B-721: 色数を絞って順序ディザをかける後処理（CompositorEffect）。「今どきレトロ」の味付け。Forward+ 専用。判定: パラメーターの単体テスト＋画像確認。

## 内容（エンジン本体の変更）

- `scene/resources/uzu_palette_dither.{h,cpp}`（新規）: `UZUPaletteDither`（CompositorEffect）。
  - パラメーター:
    - `levels`: チャンネルあたりの段数（既定 6 ＝ 216色、2〜64）
    - `dither_strength`: 4×4 のベイヤー模様で、丸めの境をずらす量（0〜1）
    - `dither_scale`: 模様の1マスの画素数（1〜8。大きいほどドットが目立つ）
  - 量子化する空間: CompositorEffect はトーンマップの前（リニアの HDR）で動く。そのため、表示に近いガンマ空間（1/2.2）に移して量子化し、元に戻す。
  - 処理: 1画素ごとに独立なので、色のバッファをその場で1回読み書きする（作業用のテクスチャは使わない）。
  - 同じ式を C++ の `quantize(color, pixel)` と `get_dither_threshold(pixel)` にも持たせた。描画しなくても結果を確かめられる。
- 登録と、ドキュメント（doc/classes/UZUPaletteDither.xml。U.ZU Engine 独自であることも書いた）。
- ツール: `look palette --scene ... [--levels 6] [--strength 1] [--scale 1]`。WorldEnvironment のコンポジターの最後に足す。MCP の look_palette も同じ。

## 確認

- 単体テスト: `tests/scene/test_uzu_palette_dither.cpp`（新規、2件）
  - 既定値、範囲の制限、登録。
  - ディザなしでは、どの色も段の値（ガンマ空間で 0, 1/3, 2/3, 1）に揃う。アルファは保たれる。
  - ベイヤーの閾値: 16個が −0.5〜0.5 に収まり、平均が 0 で、4画素ごとに繰り返す。
  - ディザありでは、段の間の平らな色が2つの段の混ざりになり、平均が元の明るさに近い。
  - マスを大きくすると、模様が粗くなる。
- 全テスト: **1495件中 1495 pass**（2件増えた）。ビルドの警告: なし。clang-format: pass。
- 画像（A-1、ソフトウェア Vulkan）: `ai_loop/look_samples/compare/b721_palette_dither.png`（上: HD-2D、下: さらに段数 5・マス 2 px）。色数が絞られ、なめらかな面が点描のような模様になる。
- `uzu.py selftest all`、`mcp_server.py --self-test`: ok。
