# B-305 乱数の種の固定（selfplay.sh --seed） — claude (2026-11-17)

- ブランチ: ai-native に直接反映（Q8 の承認による）。
- BACKLOG B-305（B-302 の R5）: 乱数を使うゲームでも、自己検証プレイを再現できるようにする。

## 内容

- `selfplay.sh --seed N`: コピーしたプロジェクトに `--uzu-seed N` を渡す。
- `selfplay/replay.gd`: 一番先に動く autoload なので、ゲームのノードが動く前に `seed(N)` でグローバルな乱数（randi・randf など）の種を固定する。
- 限界: ゲームが自分で `randomize()` を呼んだり、自分の RandomNumberGenerator を作ったりすると、その乱数は固定されない。スクリプトの先頭に書いた。
  - テレメトリの session ID は専用の乱数で作るので、種を固定しても毎回変わる（個人を追跡しないため、意図どおり）。

## 確認

- `selfplay_selftest.sh` に追加した。`randi()` の値をチェックポイント名として記録する小さなゲームで試した。
  - 種 1 で2回: 同じ値。
  - 種 2: 違う値。
  - 既存の再現性の検査（種なし）も ok。
- 全テスト: C++ の変更はないので、B-103 と同じバイナリで 1481/1481 pass。
