# B-109 macOS のアプリバンドルのアイコン — claude (2026-11-18)

- ブランチ: ai-native に直接反映。着手前に CLAIMS へ宣言を push した。
- BACKLOG B-109: B-108 のローカル確認で、macOS の icns が Godot のまま残っていると分かった。
  - 判定: macOS 向けに書き出したアプリのアイコンが U.ZU になること。

## 内容

- `misc/logo/uzu/macos_icons.py`（新規）:
  - 公式の `misc/logo/icon.svg` を、Chromium（Playwright）で描く。
    - 大きさは Apple のアイコングリッドに合わせ、1024 px の中に 824 px の角丸四角を置く。
    - Python の Playwright がなければ、Node の playwright を使う。
  - Pillow で icns を書く（16〜1024 px の全サイズ）。
  - `--check` は、書かずに「ファイルの最大サイズが絵と一致するか」だけを確かめる。
  - 絵は新しく描いていない。ダウンロードもしない（Windows の `windows_icons.py` と同じ方針）。
- 差し替えた icns:
  - `misc/dist/macos_template.app/Contents/Resources/icon.icns`: 書き出したゲームのうち、自分のアイコンを指定していないもの。
  - `misc/dist/macos_tools.app/Contents/Resources/GodotLG.icns`: エディタのバンドル。参照名を変えないため、ファイル名は昔のまま。
- エディタの plist（`Info.plist`、`Info_arm64.plist`、`Info_x86_64.plist`、`misc/dist/macos/editor_info_plist.template`）から、`CFBundleIconName`（GodotLG）を外した。
  - macOS 11 以降は、これがあると `Assets.car`（Icon Composer の旧 Godot アイコン）を優先する。
  - Assets.car は macOS の actool でしか作れないので、ここでは作り直せない。
  - 外したことで、CFBundleIconFile の icns が使われる。Assets.car は、上流との merge を楽にするため、削除せずに残した（使われない）。
- 書類の種類ごとのアイコン（Project.icns、Scene.icns など）は、今回は変えていない。
- `misc/logo/uzu/README.md` に、手順と範囲を書いた。

## 確認

- `macos_icons.py --check`:
  - 差し替え前は、2つとも不一致（ok=false。旧ファイルは Godot の絵で、サイズの構成も違う）。
  - 差し替え後は、2つとも一致（ok=true）。サイズは 16@2x〜512@2x の8種。
- 1024 px と 32 px の画像を取り出して、目で確かめた: U.ZU の渦が、角丸の紺地に載っている。
- plistlib で読み直した: CFBundleIconFile は GodotLG.icns のままで、CFBundleIconName はない。
- エンジンのコードは変えていない（書き出しは、プロジェクトのアイコンがあれば今までどおり、それを icns に変換する）。そのため、全テストへの影響はない。
- この環境に macOS はない。書き出したアプリと、エディタのバンドルの見た目は、macOS 実機で確かめる必要がある（BACKLOG は未完了のまま、進捗だけ書いた）。

## 残り

- macOS 実機での確認（ローカル、またはオーナー）:
  - エディタの .app のアイコン。
  - 自分のアイコンを指定していないプロジェクトを書き出した .app のアイコン。
- 必要なら、書類のアイコン（Project.icns など）の U.ZU 化を、別の項目にする。
