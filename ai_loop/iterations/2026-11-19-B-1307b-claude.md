## 内容

- **`UZUUI.create_world_material(world)`**: 枠の、動く装飾（canvas シェーダー）。

  | 世界 | 動き |
  |---|---|
  | fantasy | 金のきらめきの帯が、ときどき斜めに走る |
  | wafu | ゆっくり静かな艶 |
  | sf | 走査線が下へ流れる |
  | horror | 壊れかけの灯りのような、ちらつき |
  | persona | 速い白いフラッシュ |
  | pixel | 段で区切った点滅（コマ落とし） |

  - 素材は、枠だけに付く。中の文字や部品は、自分の素材のまま（use_parent_material は切ったまま）。
- **`UZUUIWorld`**（新しいノード。画面と一緒に保存される）: 画面が始まるときに、次をする。
  - 枠（パネル・タブ・ボタン）に、世界の動く装飾を付ける。
  - 一番外のパネルと会話窓を、世界の動き（`UZUUIJuice.apply_world_motion`）で開く。
  - ボタンを、ホバーで膨らませる（`hover_pulse`）。
  - 動いている間は、リボンをゆっくり揺らし、会話窓の送り印 ▼ を点滅させる。pixel では、揺れも段で区切る。
  - `get_stats()`（装飾した数、開いた数、時間）と、UZUUIJuice のイベントログで、動きを記録できる。
- **ui_tool.gd**: テーマに `world` があれば、`WorldMotion`（UZUUIWorld）を画面に足す。`uzu.py ui --world` だけで、動く UI になる。
- **UI レポート（B-1305）**に `motion` を足した:
  - 内容: 世界ノードの統計、UZUUIJuice のイベント数（open/start など）、今動いているアニメーションの数、動く枠の数。
  - 何も動いていない画面には、「world を足せば動く」というヒントを出す。
  - あわせて直したもの: 1つの部品の中の重なり（会話窓の名前札が窓の上の縁に乗るのは、意図どおり）を、overlap と誤って指摘していた。画面の同じ子に属するパネル同士は、比べないようにした。
- ドキュメント: `doc/classes/UZUUIWorld.xml`（新規）。UZUUI.xml に create_world_material を足した。
