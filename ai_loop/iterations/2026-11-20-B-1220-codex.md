# B-1220 リグ付きモデルのモーションと連番スプライト — Codex

- `uzu.py anim <project> motion`／MCP `animation_motion` は、インポート済みの二足歩行リグを参照するシーンと `MotionPlayer` を作る。待機・歩行・走行の3クリップに、速度・手足の振り幅・上下動の重さ感を設定できる。標準と名前が異なるボーンは JSON で対応付けられる。
- `uzu.py anim <project> align`／MCP `animation_align` は、各 PNG の透明余白を除き、ピクセル等倍のまま共通キャンバスの下辺中央に置く。出力サイズ、元画像の使用範囲、配置位置を返す。
- [実行例と設定](../animation/README.md)。クリップはその場再生で、ゲーム内の移動は `CharacterBody3D` などが担当する。
