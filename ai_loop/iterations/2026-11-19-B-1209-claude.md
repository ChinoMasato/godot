## 内容

- **`engine pbr-preset --name NAME --out res://materials/pbr [--size 256] [--seed 1]`**: 継ぎ目のない下地の画像を、手続きで描く（FastNoiseLite の seamless と、簡単な模様。外部の画像は使わない）。それを UZUPBRFromImage（B-902）で、albedo／normal／ORM の PNG にする。
  - プリセットは7種:

    | 名前 | 模様 | UZUPBRFromImage の種類 |
    |---|---|---|
    | wood | 板と木目と継ぎ目 | wood |
    | stone | セル状の石畳と目地 | cobble |
    | brick | 互い違いの煉瓦と目地 | brick |
    | dirt | 土と小石 | ground |
    | grass | 草の筋 | ground |
    | plaster | 漆喰 | plaster |
    | tile | 瓦。重なりの陰を付けた | brick |

  - 下地の色は明るく、ほぼ無彩色にした。モデル自身の色で着色するため（赤い屋根は、赤いまま瓦になる）。
- **`engine pbr-assign --scene --assign 'House*:plaster,Roof*:tile,Ground:grass' [--scale 0.5] [--no-tint]`**: 名前の型に合うノードに、ORMMaterial3D を付ける。
  - 中身: albedo、normal、ORM、世界座標の triplanar。triplanar なので、大きさの違う箱や平面でも、テクスチャの目の大きさがそろう。
  - 色: 今の色で着色する（少し明るくする）。
- **`uzu.py look <project> pbr --scene --assign ...`**: 足りないプリセットを作り、インポートし、割り当てる。この1コマンドで済む。
- **リッチ度レポート（B-1204）**:
  - `materials`（素材の数）と `untextured_share`（テクスチャのない素材の割合）を足した。素材のないメッシュは、既定の灰色として数える。
  - 素材が3つ以上で、半分を超えると、`look pbr` を勧めるヒントを出す。
- MCP: pbr_presets_apply。`uzu.py selftest engine` に2項目を足した（地面・壁・屋根に当てると、割合が 1.0 → 0.0。triplanar と normal の参照が保存される。知らないプリセットは一覧付きの誤り）。

## 残り

- 『灯りの欠片』の家・地面・道への適用（リード）:
  - ゲームのスクリプトが作るメッシュに、`res://materials/pbr/` の素材を付ける。
  - または、地面などをシーンに置いてから `look pbr` を当てる。
- Blender ブリッジ（B-1201）の工程への組み込み:
  1. ベース画像を UZUPBRFromImage に通す。
  2. GLB に焼いて書き出す。
  - Blender のある環境で行う。
- プリセットの見た目の好み（色、目の細かさ）は、GPU の実機とオーナーの目で詰める。
