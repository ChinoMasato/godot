# B-727 水のシェーダーの GPU 確認 — Claude Code ローカル（Windows、RTX 4050、2026-11-19）

ai-native 508d5e4764（B-727）をビルドし、見本 water に `look apply` → `look water --position 0,0,-7.5 --size 16,21`（shoot_all.sh の water_surface と同じ）をかけて、3 つの描画方式で撮った。1920x1080 で頼んで、窓は 1920x1061。
道具は新しく足した `ai_loop/windows/water_gpu.py` で、描画方式 × 場合（水なし／水あり／反射なし／屈折なし）を撮って測る。

## 結論

- **3 つの描画方式（Forward+、Mobile、Compatibility）とも動く。** シェーダーの誤りは 0。
  - 深さの色、岸と岩・杭のまわりの泡、塔と杭の映り込み、手前の物が水に引き込まれないこと、をどれも画像で確かめた。
- **速さは問題ない。**
  - 水のぶんの増え: Forward+ で +1.4 ms、Mobile で +0.75 ms、Compatibility で +0.62 ms（1080p、中央値）。
  - そのうち自前の反射（28 歩）は 0.25〜0.36 ms。
- **見た目で直したい所がある（クラウド担当の look_preset_3d.cpp のシェーダー）。**
  1. **波の模様が四角いレンガ状に見える。** 3 つの描画方式すべてで、反射を切っても残る（`b727_gpu_zoom_windows.png` の右上）。値ノイズの格子が見えている。滑らかな補間（smoothstep／quintic）にするか、格子を回す・ずらすと消えるはず。
  2. **反射が横に裂けて階段状になる**（塔と杭の映り込み）。28 歩で止めていて、当たった所の詰め（二分探索の数回）がないため。2〜4 回の二分探索で滑らかになるはず。
  3. **岸の泡が四角い塊で、縁が硬い。** 1 と同じノイズの格子のせい。
  4. **画面の下端に、細い明るい線が横に一本出る**（3 つとも）。水面の手前の端（z = 3）が、手前の岸の下から覗いているように見える。見本の形か水面の大きさの問題で、小さい。
- Compatibility は、水も空も Forward+ より暗く、色が濃い。水なしでも空が灰色なので、B-727 のせいではない（Compatibility の見た目の差。クラウドの記録の値でも同じ傾向）。

## GPU のリセットについて（正直な記録）

- 一括撮影（12 枚）の間に、NVIDIA ドライバーのリセット（イベント 153）が 1 分の間に 3 回あった（23:58:02、23:58:40、23:58:48）。
  - Forward+ の屈折なしは、やり直しも含めて 2 回とも描画中に「Vulkan fence を待てない（VkResult −4、デバイスを失った）」で落ちた。
  - 数分後に 1 件だけ撮り直すと、リセットなしで撮れた。
- この PC は 9 月から GPU のリセットが起きている（GPUFLAKE の記録）。今日の B-726 の撮影ではリセットはなかった。
- 水のシェーダーが原因とは言い切れないが、水を撮ったときに続けて起きたので、今後の水の撮影で再発するかを見る。
