## 内容

- **枠の素材**（`UZUUI.draw_frame`／`create_frame_style`）: 9-slice の画像を、手続きで描く。
  - 素材: wood（木目）、metal（ヘアライン）、parchment（羊皮紙。縁が焼ける）、stone（ひび割れ）、glass（走査線と、縁の光）、halftone（網点）、grime（汚れと傷）、flat。
  - 形: rounded、chamfer（角を切る。SF）、skew（平行四辺形。ペルソナ風）、pixel（硬い縁で AA なし。角は1ドット欠く）。
  - 縁: 上が明るく、下が暗いベベル。
  - 角飾り: rivets、nails、brackets（金の L 字）、diamonds（菱）。9-slice が保つ角の部分に描くので、どの大きさでも角に残る。
  - 影: 柔らかい影。網点とピクセルでは、ずらしたベタの影（漫画やドット絵の流儀）。
  - 真ん中は、32 px ごとに繰り返す値ノイズで描き、TILE_FIT で敷く。大きな枠でも、質感の目が伸びない。
  - 手続き生成だけで作り、外部の素材は使っていない（B-1307 の条件どおり）。
- **世界観テーマ**（`UZUUI.create_world_theme(name)`、`get_world_names`、`get_world_options`）:

  | テーマ | パネル | ボタン | その他 |
  |---|---|---|---|
  | fantasy | 木、金の L 字飾り | 羊皮紙 | 赤いゲージ |
  | wafu | 羊皮紙（和紙）、朱の菱飾り | 朱 | 角は小さめ |
  | sf | 暗いガラス、シアンの光る縁、切り角 | 同じくガラス | |
  | horror | 汚れた暗い赤、釘 | | |
  | persona | 網点の赤、平行四辺形、黒い縁、ベタの影 | 黒の斜め | 黄のゲージ |
  | pixel | 濃紺、白いドット枠、AA なし | | 緑のゲージ（B-1212 のピクセル規律に合わせ、縁を硬くした） |

  - ゲームの部品は、テーマの type variation（UZUGauge、UZUTalk、UZUNameTag、UZUSlot、UZURibbon）で着せ替わる。
  - テーマのメタデータに、`uzu_world` と `uzu_motion` を持たせた。
- **動きの言語**（`get_world_motion`）: 第2段（B-1304）が読む値として、先に定義した。
  - persona: 0.18 秒、大きなオーバーシュート（2.6）。
  - sf: expo の in_out で、機械的。
  - fantasy: 柔らかい back。
  - wafu: quart で静か。
  - horror: sine で、ゆっくり。
  - pixel: 4 段のコマ落とし。
- **定番部品**:
  - `make_gauge`: セグメント付きのゲージ。1セグメント 12 px で、隙間を空けて繰り返す。
  - `make_talk_window`: 名前札が窓の上の縁に重なり、右下に送り印 ▼ が付く会話窓。
  - `make_item_slot`: 沈んだ四角に、個数が付く。
  - `make_ribbon`: リボンの見出し。
  - `make_separator`: 両端が消えていく線の、真ん中に菱を置いた区切り線。
- **ui_tool.gd**: テーマに `world` を足した。種類 Gauge／Talk／Slot／Ribbon／Separator を足した。`uzu.py ui --world NAME` で、1つの値だけで切り替わる。MCP ui_build にも `world` を足した。
- 見本: `ai_loop/look_samples/specs/world_ui.json`（リボンの題、状態の窓（ゲージ2本、区切り線、スロット4つ）、メニュー、会話窓）。

## 確認

- 同じ `world_ui.json` を6つの世界で、村の上に撮った: `ai_loop/look_samples/compare/b1307_worlds.png`。
  - 木と金の飾り、和紙と朱、ガラスとシアン、汚れと釘、網点の赤い斜め、ドット枠が、それぞれ1つの値だけで切り替わった。
  - 配置と文字は同じまま。
- 単体テスト（`tests/scene/test_uzu_ui.cpp` に2件を追加）:
  - **枠**:
    - 真ん中が 32 px ごとに繰り返す（継ぎ目なし）。
    - 木目に、明るさの幅がある。
    - 角に金の飾りがある。
    - ピクセル枠に、半透明の画素が1つもない（AA なし）。角は欠ける。
    - ガラスの縁が、真ん中より明るい。切り角がある。
  - **テーマ**:
    - 6つの世界のすべてに、5つの type variation と、メタデータがある。
    - fantasy と sf の枠は違う。
    - 動きは、persona のオーバーシュートが fantasy より大きく、pixel は段があり、sf は 0。
    - 知らない世界は null。
  - **部品**: ゲージの幅（12×セグメント数）、会話窓の名前札・台詞・▼、スロットの個数、リボンの題、区切り線。
- 全テスト: **1550件中 1550 pass**。ビルドの警告: なし。clang-format: pass。
- `uzu.py selftest all`（fontTools 入りの venv）: ok。world の4項目（fantasy／sf が部品の variation と一緒に保存される、2つの世界で中身が違う、知らない世界は誤り）を含む。`mcp_server.py --self-test`: ok。
